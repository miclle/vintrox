### 测量位置与判定

1. 对电源输出端、Hub 输入端、光驱桥接板/光驱端及硬盘输入端分别设测点；Pi 5V 一并记录。电压参考对应负载端 GND，不只看电源空载电压。方案 B 保留每支路及总电流测点。
2. 瞬态优先用示波器＋电流探头，或低阻分流器＋合适差分测量；记录采样率、带宽、触发条件和测点。避免接地示波器地夹跨接不同电位。分流器与转接板自身压降需计入。
3. 普通 USB 电流表仅辅助平均值观察，可能漏掉短时峰值并增加压降；记录表具，并确认其是否保留 USB 3 通道。反向电流在合适的串联测量夹具中测，不将电流档直接跨接电源正负极。
4. 设备端可先用 4.75～5.25V 作保守筛查，最终以实际设备、桥接板及对应接口条件中更严格的规格为准；记录最低值、过冲、纹波及持续时间。这不是所有 USB 状态统一适用的规范阈值。
5. 保留失败波形和日志。任何电气越限、非预期重连/复位、I/O 错误、校验不一致或播放中断，都应归因并复测；不能靠自动重试掩盖失败，也不能仅凭单次现象排除线材/桥接器因素。

### 软件和数据访问步骤

在树莓派上的仓库根目录，先保存测试前状态；运行期间在独立终端持续收集带时间信息的内核日志，测试后再次保存状态：

```bash
bash scripts/usb-optical-drive.sh status
bash scripts/usb-optical-drive.sh logs
lsusb -t
lsblk -o NAME,MODEL,TRAN,SIZE,FSTYPE,MOUNTPOINTS
sudo journalctl -k -f
```

`vcgencmd get_throttled` 在当前系统支持时记录测试前后值；`0x0` 不能证明外设端没有瞬时压降。`status` 不代替 `lsusb -t`，后者用于记录设备实际协商速率及共享链路。命令和播放器使用方法见 [USB 光驱操作文档](usb-optical-drive.md)。

- 数据光盘使用已知正常介质，按操作文档只读挂载，并与已知校验值或稳定基准比较。CD-DA 使用列曲/播放命令，不按数据盘挂载；完整播放、暂停、跳曲及退盘另记录。
- 硬盘只在用户指定的测试目录中新建有明确名称的测试文件；记录大小、读写量与速率，刷新后回读校验，并确保文件实际位于该硬盘而不是系统盘。不能以缓存命中当作持续存储负载。
- 不向整盘/现有分区写入测试数据，不改分区或格式化。人为切断 Hub/外设电源的测试先停止访问并刷新、卸载；PD 拔插测试在电池系统已具备连续供电条件后进行，不把直接拔硬盘电源当作切换测试。

首轮建议分别完成 20 次冷启动、20 次光驱插/退循环，以及至少 2 小时 USB 并发运行；硬盘启动/唤醒需遵守实际设备支持的方式。每类分别记录实际次数、成功数和失败数，不以合计次数代替。此处是建议测试量，不是已完成次数、用户确认的寿命指标或整机续航保证。PD 拔插次数和低电量测试条件在选定系统后明确，测试前不宣称无缝 UPS。
