## 2. 功能与电气验证

| 编号 | 项目 | 通过条件与记录 |
| --- | --- | --- |
| T-01 | 光驱 USB 桥接 | 稳定识别，音乐 CD 列曲、播放、暂停、跳曲和退盘；记录适配器 |
| T-02 | 光驱顶部进碟姿态 | 在临时支架竖装、入口朝上，完整播放并重复插退盘，记录次数及失败 |
| T-03 | HDMI 显示 | Pi micro-HDMI 接驱动板，独立供电，记录分辨率、亮度与输入控制 |
| T-04 | 存储并发 | 硬盘访问、光驱读取、网络及媒体播放下无 USB 重连或欠压 |
| T-05 | 音频 | 声道正确，DAC→功放/RCA 路由清楚，底噪/削波/爆音可接受 |
| T-06 | 功放限制 | 4Ω 负载下校准增益/输入或限制器，持续输出不超过每声道 10W；记录测量条件 |
| T-07 | 振动 | 正常及较大音量下光驱不跳读、机箱无明显共振；检查硬盘影响 |
| T-08 | 电源模式 | 外接、电池、充电运行均稳定，无倒灌及超出模块能力 |
| T-09 | 外部电源拔插 | 记录循环次数、最低供电电压，Pi 不重启、外设不掉线、屏幕不闪断 |
| T-10 | 电池关机 | 低电量正常关机先于保护硬切，之后切主要负载；记录待机电流及重启方式 |
| T-11 | 热测试 | 连续运行及充电运行记录 Pi、功放、驱动板、电源及电池温度，符合各器件额定值 |
| T-12 | 续航 | 亮屏音乐/熄屏音乐/本地视频分别记录配置、时长和关机剩余电量 |
| T-13 | 维护 | 不破坏外壳可更换电池、光驱、硬盘；顶槽操作及侧面音响无遮挡 |
