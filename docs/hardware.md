[Pi 4B 官方机械图](../references/raspberry-pi-4b/README.md) 已归档；尺寸数值统一登记在验证清单。其余部件按 [资料取得方式](validation.md#15-确认型号后查资料与装配实测) 先核对型号，再查相应规格；官方名义、商品标称和实测结果保持分开，不用整台 iPad 的尺寸代替拆机面板。

此前树莓派日志显示 SSK 存储挂在 USB 2.0 路径（480M、usb-storage），USB 3.0 总线未列出设备。该记录只描述当时连接，不代表硬盘本身不支持 USB 3.0。先检查连接端口、线材和桥接器；不要把现有存储直接写成已确认 SSD。

屏幕驱动板已由用户描述支持 HDMI；本次提供的商品图将插座标为 mini-HDMI，尚未完成与树莓派的实际显示联调。Pi 的 micro-HDMI 输出接驱动板 mini-HDMI 输入，选线前核对两端实物；屏幕电源另接，两个 Type-C 的分工与额定值待查。不依赖屏幕音频输出，也不默认支持触摸。

## 3. 光驱验证

已取得 [本体及组合测绘照片](validation.md#16-光驱与-usb-转接器照片测绘记录)。继续补齐铭牌、裸露连接器、固定孔和含突出物的最大外形；复核组合量程与夹持边界，确认接口并核对额定电压。随后验证 Linux 识别、CD-DA 读取、暂停/跳曲、无盘启动、连续播放与退盘，再测试入口朝上的竖装姿态、插退盘净空和扬声器工作时的读盘稳定性。

竖装测试通过前不加工最终顶部槽口；水平安装只作为失败后的备选，需重新评估进深。

有关 Disks 中设备周期性出现/消失、辅助供电后恢复读取的用户现场观察，以及安装/诊断脚本，见 [USB CD/DVD 光驱使用与排障](usb-optical-drive.md)。该观察不能代替 T-01 音乐 CD 播放、重复退盘或竖装验证。

## 4. 选型原则

优先复用移动硬盘和完整音箱，SSD 是未来缩小体积、减少机械噪声的替换选项。功放以 4Ω、每声道 10W 额定音箱为负载，不按电商“2×80W”标题选型。不能将截图中单元标注再次乘以两个来扩大每声道功率。

电源模块先确认功能再比价：PD 诱骗、升降压、充电管理、BMS 和电源路径管理是不同职责；低价或支持“边充边放”均不能证明符合整机要求。

验证表见 [测量与验证](validation.md)，电源约束见 [电源设计](power-system.md)。

## 4.2 候选淘汰与待实测边界

- 无上行防反灌依据，或检测到外设电源向 Pi 送电：不进入带数据运行测试，先更换/修正接口。
- Hub 总功率足够但单口能力不足：不绕过限流，不并接两个口；改用自供电桥接器/独立分路。
- 仅有“大电流充电口”而无同时数据能力：不能用作光驱或硬盘的数据口。USB 2.0 光驱接 USB 3 Hub 不自动提高允许电流，详见 [电源设计](power-system.md) 引用的 USB-IF 政策。
- Y 线供电来源或内部连接未知、桥接板 VBUS 与外部 5V 分离不明：保持待确认，不将两个独立 5V 电源接入同一负载。
- 额定参数符合但启动、压降、并发或热测试未完成：仍为候选；单设备读盘成功不代表 T-04/T-08/T-09 通过。
