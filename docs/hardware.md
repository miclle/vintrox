## 2. 光驱：最先解决的接口问题

来源是 **MacBook Pro (13-inch, Mid 2010)**，系统识别的型号为 **MATSHITA DVD-R UJ-898**，此前在原机器内能正常工作。

验证顺序：

1. 拆机前后拍照记录驱动器标签、实际连接器和机械尺寸，不凭型号推断引脚定义。
2. 按真实连接器选用适配的 SATA/slimline SATA 或 Apple 特定接口至 USB 桥接方案；绝不可在未确认引脚时接电。
3. 核实驱动器工作电压、启动峰值电流与适配器供电能力；必要时使用独立供电的合规适配器。
4. Raspberry Pi 识别后检查设备节点和光盘能力；测试音乐 CD 读取、连续播放、插/退盘及无盘启动。
5. 确认进出盘槽的正反方向、面板开孔尺寸、固定孔位、防尘和振动隔离。

**不要**直接假设普通 USB 数据线即可驱动旧 Mac 光驱。

## 3. 显示屏：区分屏幕与驱动板

项目已有一套 iPad 拆屏改装显示器，用户描述其支持 USB-C 连接同时传输视频与供电，且没有必要使用屏幕的音频输出。

- 拆屏面板本身通常不能直接接 Raspberry Pi；应连接现有配套驱动板。
- 记录驱动板的具体输入：HDMI、USB-C（是否 DP Alt Mode）、触摸 USB、DC 电源等。
- **Raspberry Pi 4B USB-C 口主要用于电源，不是通用 USB-C 视频源**。建议优先验证 Pi 的 micro-HDMI 输出是否可接显示板的 HDMI 输入。
- 如果屏幕仅接收 USB-C DP Alt Mode，则需验证主动 HDMI → USB-C DP 转换设备的兼容性与供电，不能用普通无源转换线想当然。
- 触摸功能需单独确认是否可通过 USB 回传；记录屏幕尺寸、背光功耗及安装孔位。

## 4. 计算平台和 USB 拓扑

初期使用 Raspberry Pi 4B，保留 USB 3.0 优先供给 SSD，光驱和 DAC 优先隔离功率尖峰及噪声影响。实际端口分配和外接有源 Hub 是否需要，取决于负载测试。

必要验证：同时读取 CD、从 SSD 播视频、访问网络时是否稳定；测量低压供电压降和重启/拔插情形。主控散热方案应在封闭机箱之前确定。

## 5. 功放与扬声器

TPA3116D2、TPA3118D2 都可作为早期候选，不依据“2×80W”商品标题采购。功放可用功率取决于实际芯片、供电、负载阻抗、散热、失真定义和板卡设计。对于桌面近场设备，重点是低噪声、稳定性和与扬声器的匹配，而不是标称峰值瓦数。

先选扬声器单元及预期箱体结构，再决定功放与电源；不要在确认负载前追求大功率。

每个部件测试时记录：`设备/版本｜连接方式｜电压/电流｜系统版本｜测试步骤｜结果（通过/失败/待测）｜照片/日志｜下一步`。
