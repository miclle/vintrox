# 设计决策与待验证事项

本文件防止“讨论过”“倾向采用”被误记为“已验证/最终选型”。

## 状态定义

- **已决定**：产品目标或设计原则已确认；不是实物验证结论。
- **候选**：目前推荐方案，可被测试结果推翻。
- **待验证**：依赖实际部件、测量或软件实验。
- **已验证**：有可复现的测量、截图、日志或测试记录（当前无整机集成实测记录）。

## 现代打印方案（2026-10-18）

- D-027：用户指定[分层桌面设备参考](https://www.pinterest.com/pin/950752171346584667/)，认可其外观与实用性。采用科技、现代、个性的设计目标；具体借鉴内嵌屏幕、下部控制区、分层外壳与可拆维护盒体，属待细化候选，不照搬参考的未知功能。
- 新打印方案优先评估“屏幕前框＋独立控制区＋分体壳片＋内部模块托架＋可拆后盖/托盘”；已采用浅灰＋石墨黑＋橙色点缀、斜向侧格栅及当前35件结构；打印材料、紧固方案及工程尺寸仍待试制，约160mm本体深度仍为布局目标。
- D-028（先前确认，后续外观目标由 D-029 更新）：已生成 [vintrox-terminal斜面模块化桌面终端](terminal-model.md)，此前木壳等旧设计已移除；参数化分件模型有35个打印件、14个硬件占位；本体234 × 212 × 160mm，含脚及控件总包络234 × 217 × 170mm。外罩、控制面板、屏幕压框、光驱/音箱/电池托架、中央骨架/托盘、格栅及后盖分别建模，导出总装与单件STEP/STL；完成保存读回和静态几何/参数检测。原配色方向采用浅灰＋石墨黑＋橙色点缀；3mm名义壁厚、4mm底盘、3.4mm孔和256mm假设成型空间均待验证，未知硬件尺寸仍是假设；未打印、未实物装配，不表示M4验收通过。

- **D-029，已决定**：用户要求尽量做成与本地 [Alexander Shevchuk Drone 参考](../references/alexander-shevchuk-drone/README.md)一致的外观效果，按现有屏幕尺寸调整整体比例。造型优先，允许音质为造型让步；不再将最小宽度、160mm 本体深度或原灰黑橙配色作为新方案的硬约束。前罩、提手、翼板、侧面圆环、喷口及表面效果均纳入还原目标，具体比例、配色与工艺待建模/打样；不承诺平面屏能原样复现曲面屏。3D 打印、不采用木制材料、侧向 L/R、顶部进碟候选及核心功能继续有效。原“撤销复古外形”的表述不再用于排除本次明确选择的参考特征，也不自动改回早期木壳方案或旧品牌文案。

## 2026-10-16 替代的早期草案

- 撤销屏幕左右正面布置音箱的示意；改为机身两侧发声。
- 撤销约 270 × 210 × 170mm 的参考外形作为设计基线；当前尺寸待测。
- 原“仅外置 DC 适配器”的描述更新为 Type-C 输入和内置电池系统。
- 存储不再默认 USB SSD；保留已有移动硬盘，SSD 只作未来替换选项。
- 每声道 10W/峰值 18W 已明确，不再按每箱两个单元重复累加。
- 屏幕 HDMI 支持已由用户确认，但 Pi 联调、供电、触摸和总尺寸仍待测。

新增关键验证：光驱竖装、音箱拆分与独立尺寸、PD 档位、启动峰值、外部电源切换、低电量关机、充电运行温升。详见 [测量清单](validation.md)。

## 更新方式

每当验证完成：

1. 在相应主题文档中更新实测参数。
2. 将相关状态改成“已验证”，附测试条件、结果、日志/图片路径。
3. 如果推翻原候选，说明原因与替代方案。
4. 保持此决策表与 BOM、路线图一致。

不要删除失败的实验记录；它们有助于后续硬件迭代。
