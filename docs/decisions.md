# 设计决策与待验证事项

本文件防止“讨论过”“倾向采用”被误记为“已验证/最终选型”。

## 状态定义

- **已决定**：产品目标或设计原则已确认；不是实物验证结论。
- **候选**：目前推荐方案，可被测试结果推翻。
- **待验证**：依赖实际部件、测量或软件实验。
- **已验证**：有可复现的测量、截图、日志或测试记录（当前无整机集成实测记录）。

## 2026-10-16 替代的早期草案

- 撤销屏幕左右正面布置音箱的示意；改为机身两侧发声。
- 撤销约 270 × 210 × 170mm 的参考外形作为设计基线；当前尺寸待测。
- 原“仅外置 DC 适配器”的描述更新为 Type-C 输入和内置电池系统。
- 存储不再默认 USB SSD；保留已有移动硬盘，SSD 只作未来替换选项。
- 每声道 10W/峰值 18W 已明确，不再按每箱两个单元重复累加。
- 屏幕 HDMI 支持已由用户确认，但 Pi 联调、供电、触摸和总尺寸仍待测。

新增关键验证：光驱竖装、音箱拆分与独立尺寸、PD 档位、启动峰值、外部电源切换、低电量关机、充电运行温升。详见 [测量清单](validation.md)。

## 更新方式

每当验证完成：

1. 在相应主题文档中更新实测参数。
2. 将相关状态改成“已验证”，附测试条件、结果、日志/图片路径。
3. 如果推翻原候选，说明原因与替代方案。
4. 保持此决策表与 BOM、路线图一致。

不要删除失败的实验记录；它们有助于后续硬件迭代。
