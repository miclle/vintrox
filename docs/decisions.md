# 设计决策与待验证事项

## 状态定义

- **已决定**：产品目标或设计原则已确认；不是实物验证结论。
- **候选**：目前推荐方案，可被测试结果推翻。
- **待验证**：依赖实际部件、测量或软件实验。
- **已验证**：有可复现的测量、截图、日志或测试记录（当前无整机集成实测记录）。

## 更新方式

每当验证完成：

1. 在相应主题文档中更新实测参数。
2. 将相关状态改成“已验证”，附测试条件、结果、日志/图片路径。
3. 如果推翻原候选，说明原因与替代方案。
4. 保持此决策表与 BOM、路线图一致。

不要删除失败的实验记录；它们有助于后续硬件迭代。
