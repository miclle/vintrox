# 机箱与工业设计

VINTROX One 的外观方向是 **70 年代 Hi-Fi 气质 × 当代桌面计算机**：黑胡桃木提供温度，金属面板提供精密感，屏幕与光驱赋予其鲜明功能特征。

> 当前仅定义结构原则与布局方向。没有实测外形尺寸之前，不冻结开孔图纸或整体宽高深。

## 1. 材料与视觉语言

- **黑胡桃木**：顶板、侧板或局部饰条，体现复古家居和工艺质感。
- **金属面板**：建议拉丝铝或喷砂金属用于主前面板，方便加工按钮、旋钮和接口孔。
- **3D 打印**：仅承担光驱托架、屏幕固定座、线缆卡扣、导风结构等内部可替换件；高温处选择合适材料。
- **织物/网罩**：扬声器正面可以使用可拆卸网罩或开孔金属格栅。
- **灯光**：优先低亮度暖白/琥珀色状态提示，不强制添加装饰性 VU 表。

避免把木板作为散热件；木材、功放和电源之间保留安全热间距。木饰面尽可能采用机械连接，便于维修。

## 2. 正面交互区（布局草案，非尺寸图）

```text
┌───────────────────────────────────────────────────────────┐
│  黑胡桃木顶板 / 饰边                                        │
├───────────────────────────────────────────────────────────┤
│  ┌────────┐    ┌─────────────────────────┐    ┌────────┐  │
│  │ 左扬声器│    │   约 10.2" 主显示屏      │    │ 右扬声器│  │
│  │  网罩  │    │                         │    │  网罩  │  │
│  └────────┘    └─────────────────────────┘    └────────┘  │
│                    ── 光驱进/出盘槽 ──                     │
│  [Power]   [Prev]  [Play/Pause]  [Next]  [Eject]   (VOL) │
└───────────────────────────────────────────────────────────┘
```

这是功能位置示意，**不是承诺当前零件一定能塞入该排列**。特别需要验证屏幕占用面积、扬声器最小声学容积、槽吸式光驱方向及出入盘净空。

## 3. 内部结构分区

| 区域 | 建议布置 | 注意事项 |
| --- | --- | --- |
| 中央显示区 | 屏幕面板 + 驱动板 | 背光散热、信号排线折弯半径 |
| 光驱区 | 独立托架与导向槽 | 可拆卸、避免受力、隔离低频振动 |
| 左右声学区 | 独立扬声器腔体 | 尽量气密，阻断传到光驱的振动 |
| 计算区 | Pi + USB/SSD + 网络 | USB 插头净空、检修通道、散热 |
| 音频区 | DAC + 功放 + 音频布线 | 远离大电流电源线，减少地环路 |
| 电源区 | DC 输入 + 保险/稳压/配电 | 低压电源路径清晰、易测量、可保护 |

## 4. 后面板与接口

必需：DC 电源输入、RCA Left/Right、维护所需的接口或可开启后盖、基本散热孔。推荐预留网线、USB 的维护/扩展位置；实际是否外露取决于空间。

接口周围要保留手指和插头尺寸，不仅仅满足孔径；RCA 应有明确的 L/R 及 LINE OUT 标识。

## 5. 散热、机械与安全

- Pi、SSD、驱动板、功放的热源分别定位；明确进风/排风通道。
- 禁止将风扇排风直接吹向光盘入口造成灰尘问题。
- 木箱体与电子腔体需留阻燃、绝缘、电缆防磨和应力释放措施。
- 木材因湿度产生尺寸变化，装配孔位建议允许少量公差。
- 大面积屏幕前盖与显示面板之间考虑垫片、振动和清洁防尘。
- 底部用防滑脚垫；设备应在更换光驱/SSD 时不破坏外饰面。
- 优先使用外置认证 AC/DC 电源，机箱内只处理经过认证适配器输出的低压电；不自行在木质机箱内裸露市电接线。

## 6. 设计前必需的测量

1. 光驱长宽高、槽中心线、固定孔、插拔光盘所需空间。
2. 显示面板可见区、整体外框、驱动板与排线布局、实际热源。
3. 扬声器口径、安装深度、建议容积及格栅边界。
4. Pi、SSD、DAC、功放、DC 模块的占位和线缆弯折半径。
5. 前面板按键、旋钮的机械尺寸、操作间距及内部固定方式。

测量完成后再输出：2D 尺寸图、3D 结构模型、爆炸图、木板切割清单、金属开孔图、3D 打印 STL/STEP 与装配指南。

## 7. 首次打样策略

先用快速加工的临时底板验证位置、振动和散热；随后制作内部支架；最后才切割正式黑胡桃木板与金属装饰面，降低返工风险。
