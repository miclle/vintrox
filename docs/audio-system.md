# 音频系统设计

目标：在 VINTROX One 中实现高于板载基础音频方案的稳定双声道声音链路，并**同时支持内置左右扬声器和外部 RCA Line Out**。

## 1. 信号框架

| 阶段 | 路径 |
| --- | --- |
| 媒体与系统 | CD / 移动硬盘 / 网络 / App → Linux 音频路由 |
| 数模转换 | USB 或 I²S → 立体声 DAC |
| 分配 | DAC 的 Analog L/R → 分配/缓冲/静音电路（待设计） |
| 外部输出 | 线路信号 → RCA L/R Line Out → 外部音响 |
| 内部输出 | 线路信号 → 音量/增益 → 双声道 D 类功放 → 左右音箱 |


**硬性约束**：

- RCA 插座必须接线路信号，而非功放的扬声器输出。特别是桥接输出（BTL）功放的扬声器负端通常**不能接地**。
- 不将屏幕音频口作为主音频来源。
- 音频分配不以无条件 Y 线为默认设计：先校核 DAC 的输出驱动能力、外部负载、电平及双输出需求。
- 软件静音、上电/关机顺序、功放使能（MUTE/SD）都应考虑，减少爆音。

## 2. 方案对比

| 项目 | USB DAC | I²S DAC |
| --- | --- | --- |
| 接入 | USB，即插即用倾向较强 | GPIO/I²S，需设备树/驱动匹配 |
| 机械布置 | 模块位置灵活 | 需考虑线长与引线干扰 |
| 风险 | USB 供电噪声、兼容性与启动设备名变化 | 时钟/驱动/地线、GPIO 占用 |
| 推荐 | 第一轮先用成熟 USB DAC 快速验证 | 作为进一步集成化备选 |

需选择**具备可靠模拟线路输出**的 DAC，而非仅能推耳机的未知电平输出设备。

## 3. RCA 输出策略（待决策）

**优先评估的方案**：RCA 固定线路电平，内置喇叭有独立音量。其优点是外部有源音响/功放沿用自身音量控制；代价是需要清晰标注并防止误以为旋钮能控制 RCA。

替代方案：RCA 随主音量变化，或提供固定/可变切换。任何一种都应明确显示在 UI、文档和后面板丝印上，避免外部设备突然满音量。

同时输出与互斥切换也待样机验证：若同时输出造成底噪或地环路，可加入缓冲/隔离或继电器/模拟开关设计。

## 4. 功放候选：TPA3118D2 优先、TPA3116D2 备选

当前优先小型 TPA3118D2 双声道成品板，暂按约 12V 供电评估，最终板卡和电压未定。日常近场听音按每声道约 3～5W 使用目标评估；这不是已测声压或平均功耗。每声道持续输出设计上限不超过音箱额定 10W，并应通过增益、输入电平或限制电路落实，单靠旋钮位置不能保证。18W 峰值不作为持续输出目标。

选型评价顺序：

1. 与扬声器阻抗和额定功率匹配；
2. 在目标音量下噪声、失真与发热可接受；
3. 电源需求合理（含启动和动态余量）；
4. 模块布局便于静音、音量控制、固定与散热；
5. 板卡质量、输出滤波/EMI 处理与保护功能明确。

电商页面上的“2×50W / 2×80W”不足以证明实际连续输出；不会因同价便默认选择数字更大的板卡。

## 5. 扬声器与声学机箱

- 用户已确认左右两个音箱，每声道整体标称 4Ω、额定 10W、峰值 18W；不是每箱两个单元各自再累加功率。
- 音箱位于机身左右侧面向外发声，不在屏幕两旁占用正面宽度。优先保留原箱体，拆分和单箱尺寸待测。
- 截图标注每箱两个 80 × 45mm 全频单元；不能据此推断内接方式。整箱电气参数以上述用户确认值为准。
- 左右尽量采用独立、密封可靠的声学容积；不能直接把整机共享大空腔当作确定的音箱方案。
- 光驱与扬声器须采取结构隔振，防止低频振动造成跳读。
- 导线固定、气密、吸音材料、倒相孔等均需与最终喇叭参数一起设计。
- 留意功放散热风道和扬声器振动之间的隔离。

## 6. 噪声与安全验证

- 静音底噪：无媒体播放、移动硬盘忙、Wi-Fi 忙、光驱旋转时分别监听。
- 音量路径：低/中/高音量记录左右一致性、削波及温升。
- 外部连接：RCA 接入有源音箱，检查上电爆音、地环路与插拔噪声。
- 电源完整性：分开评估功放高动态电流与 Pi/显示供电的影响。
- 声学：播放强低频时验证光驱读取能力和机箱共振。

测量工具可用示波器、音频接口、万用表和温度探头。最终输出功率与音量目标要基于实测确定。

## 7. 暂不确定

DAC 型号、音箱灵敏度/独立外形及声学参数、放大器工作电压、内部/外部输出策略、旋钮控制的是模拟级还是软件音量，以及是否需要保护继电器/静音模块。
