# 需求与验收标准

本文件区分**必须具备（P0）**、**首版增强（P1）**和**后续探索（P2）**。P0 是 VINTROX One 可用原型的目标，不表示目前已完成。

## 1. 功能需求

| 编号 | 优先级 | 需求 | 最小验收方式 |
| --- | --- | --- | --- |
| F-01 | P0 | 识别并播放标准音频 CD（CD-DA） | 插盘、列曲、播放/暂停/跳曲/退盘完成 |
| F-02 | P0 | 本地音乐播放 | 从移动硬盘 选择文件，在扬声器上正常播放 |
| F-03 | P0 | 本地视频播放 | 在机身屏幕播放选定测试视频并输出声音 |
| F-04 | P0 | 独立内置立体声扬声器 | 左右声道正确，无明显削波或杂音 |
| F-05 | P0 | 立体声 RCA Line Out | 可接外部有源音箱/功放，电平与接地方案安全 |
| F-06 | P0 | 机身显示与基本交互 | 屏幕显示正常，触摸或替代输入可控制播放器 |
| F-07 | P0 | 网络能力 | Wi-Fi 或以太网成功联网，能正常访问网络资源 |
| F-08 | P0 | 通用计算机能力 | 可进入 Linux 桌面或应用启动器，运行兼容应用 |
| F-09 | P0 | 安全开关机与存储 | 完成正常关机、重新开机、文件系统检查 |
| F-10 | P1 | 实体播放控制 | 实现播放/暂停、上/下一曲、音量和退盘 |
| F-11 | P1 | 本地媒体库与封面 | 扫描目录，按专辑/歌手浏览、缓存封面 |
| F-12 | P1 | 音频输出独立管理 | 明确内置/外部输出策略，切换或同时输出行为可控 |
| F-13 | P1 | CD 曲目信息增强 | 联网查专辑/曲目信息；离线时也可播放 |
| F-14 | P2 | 抓轨、互联网电台、蓝牙音频等 | 单独设计与合法性/兼容性确认 |
| F-15 | P2 | 远程控制与更多扩展设备 | 发布独立接口和验收标准后实施 |
| F-16 | P0 | 内置电池独立运行 | 拔除外部电源，CD/屏幕/音响及本地媒体仍可使用 |
| F-17 | P0 | 整机 Type-C 电源输入 | 从单一电源入口供给全机；协议与档位匹配 |
| F-18 | P0 | 电量与低电量安全关机 | 有电量/低电量提示，在保护板硬切前完成正常关机 |
| F-19 | P1 | 外部电源切换与运行中充电 | 插拔输入不重启、不掉盘；充电和运行温升可控 |
| F-20 | P1 | 熄屏听音及关闭内置功放 | 操作可恢复，节电效果可测 |

说明：播放能力须以选定 Linux 发行版、播放器、驱动、硬件解码能力及实际测试文件为准。ARM 平台不保证所有桌面软件或 DRM 服务兼容。

## 2. 非功能需求

| 编号 | 要求 | 验收策略 |
| --- | --- | --- |
| N-01 | 低机械噪音 | 检查光驱读盘、扬声器播放时是否引发箱体共振 |
| N-02 | 音频底噪可控 | 静音、低音量、网络传输/移动硬盘 I/O 时听感与示波测试 |
| N-03 | 正常散热 | 连续播放视频及光盘时测量主控、功放、屏幕驱动板温度 |
| N-04 | 电气安全 | 外置合规电源、保险保护、稳压容量、接地及防短路检查 |
| N-05 | 可维护 | 不破坏木材/装饰面板即可拆卸光驱、屏幕、主板及功放 |
| N-06 | 可用性 | 网络断开后仍可播放 CD 和本地文件；异常有恢复入口 |
| N-07 | 可扩展性 | 光驱、DAC、功放、扬声器和存储可分别更换 |
| N-08 | 启动/关机稳定 | 重复多轮开关机，不产生存储损坏或外设初始化死锁 |
| N-09 | 整机尽可能小，宽度优先 | 以屏幕面板实测总宽为基准，只增加必要结构及少量控件空间 |
| N-10 | 两侧向外发声 | 音箱不在屏幕左右形成正面加宽区；检验安装与声道 |
| N-11 | 复古木制外壳 | 黑胡桃木优先，允许薄木饰面及内部骨架 |
| N-12 | 可维护电池及低待机耗电 | 电池可拆换；正常关机后切主要负载并记录待机电流 |

## 3. 基本交互路径

开机进入 VINTROX 主界面，保留以下入口：

| 入口 | 功能 |
| --- | --- |
| Disc | 音频 CD |
| Library | 移动硬盘音乐和视频 |
| Online | 浏览器及网络资源 |
| Apps | Linux 应用及桌面 |
| Settings | 音频、网络、显示、电池和系统 |


主界面是建议的信息架构，不强制使用特定 GUI 框架。优先保留键鼠/触控等标准输入作为调试后备。

## 4. 尚未冻结的关键约束

1. 改装屏的实际分辨率、接口、供电、触摸控制与安装尺寸。
2. 光驱物理接口、USB 桥接芯片、供电峰值和软件退盘能力。
3. 主控性能是否满足预期视频分辨率、音视频解码、网页与应用负载。
4. 音箱独立尺寸、拆分方式和声学结构；整箱每声道 4Ω、10W 额定、18W 峰值已由用户确认。
5. 对 RCA 的期望：固定线路电平、随音量变化，还是两者可选。
6. 设备最终体积、布局以及风扇/无风扇散热选择。

以上必须先经原型测试再冻结硬件 BOM 和机箱外形。

## 5. 优先布局与验收边界

屏幕后方竖装 UJ-898、顶部垂直吸入 CD 是优先候选，并非已验证的强制姿态。先反复测试该方向的插盘、读盘和退盘，再冻结槽口；若不可行需重新讨论布局，不直接恢复正面双音箱加宽方案。

暂不冻结整机尺寸、视频规格或电池容量。约 2 小时亮屏音乐播放只是建议的评估目标，续航须注明亮度、音量、媒体、网络、温度和电池条件。
