# VINTROX One 总体系统架构

**状态：v0.1 候选架构，未通过整机验证。**

## 1. 架构目标

使用 Raspberry Pi 4B（暂定）承担计算、存储管理、网络和界面，将光驱、屏幕、DAC、功放、扬声器设计成可独立测试及更换的模块。

## 2. 系统方框图

```text
                         ┌────────────────────────────┐
                         │      VINTROX One           │
                         │                            │
MacBook 光驱 ─ USB桥接 ───┤ USB                        │
SSD ──────────────────────┤ USB   Raspberry Pi 4B      │
旋钮/按键 ─ GPIO/USB ─────┤ I/O                        │
Wi-Fi / Ethernet ────────┤ Network                    │
                         │   │                       │
                         │   ├─ micro-HDMI ─ HDMI显示驱动板 ─ 屏幕
                         │   │                       │
                         │   └─ USB / I²S ─ DAC ───┐ │
                         └──────────────────────────┼─┘
                                                    │ Stereo line
                                           ┌────────┴───────────┐
                                           ▼                    ▼
                                        RCA 输出           功放 + 音量控制
                                                                │
                                                      L / R 内置扬声器
```

上图的 DAC 信号分支**不代表直接 Y 线分接已被验证**。需要根据 DAC 驱动能力、阻抗、静音和音量要求决定缓冲、音频分配或切换电路。

## 3. 关键数据流

### 音乐 CD

`光驱 → USB 光驱桥接 → Linux 光盘子系统 → CD-DA 读取 → 播放软件 → 音频系统 → DAC → 功放/RCA`

- CD-DA 通常不作为普通文件系统直接打开；应由支持音频 CD 的播放器/库访问。
- 退盘优先使用软件命令及驱动器支持的机制，前面板按钮是后续控制入口。
- 应测试部分老盘、无曲目元数据的情况；脱离网络仍能播放。

### 本地音视频

`SSD → Linux 文件系统 → 媒体播放器 → 视频解码/HDMI + 音频/DAC`

若操作系统默认将声音送到 HDMI，必须明确把音频路由至独立 DAC；屏幕仅承担视频显示，不依赖它的模拟音频输出。

### 普通应用

`Linux → 桌面环境/应用启动器 → 浏览器、文件管理器、其他 ARM Linux 应用`

建议早期保留标准桌面，以免定制 UI 阻碍调试；待功能稳定后叠加播放器式主界面。

## 4. 软件分层（建议）

| 层 | 职责 | 候选技术 |
| --- | --- | --- |
| OS | USB、网络、文件系统、设备驱动 | Raspberry Pi OS / 兼容 ARM64 Linux |
| 音频 | 音频路由、设备选择、音量 | ALSA + PipeWire（需选定系统版本验证） |
| 播放引擎 | CD、音乐、视频 | 支持 CD-DA 的库/播放器；mpv/VLC 等候选 |
| 服务层 | 媒体库、设备发现、按键映射、状态管理 | 本地服务；具体语言与进程边界待定 |
| UI | 主页、媒体库、设置、应用入口 | Web UI / Qt 等候选，暂不锁定 |
| 运维 | 日志、设备诊断、升级、安全关机 | systemd、日志工具等 |

可先使用成熟播放器完成闭环，确认接口后再开发定制 UI，不强制从零编写解码器。

## 5. 电源与接地概念

候选是**外置认证 DC 适配器**输入，并经专用电源模块分别提供：

- Raspberry Pi：稳定的 5V，考虑 USB SSD/光驱造成的瞬态负载。
- 显示驱动板：按真实规格提供 5V 或其它电压，严禁猜测。
- 功放：按最终芯片、板卡、扬声器阻抗和预期声压选取供电。
- 其他：控制器、状态灯、DAC/隔离模块。

不得把不同电压简单并联。电源回流、信号地与机箱的连接方式需在噪声测试中确认；整机避免从扬声器输出端引出 RCA。

## 6. 接口风险

| 接口 | 主要风险 | 先行验证 |
| --- | --- | --- |
| 光驱 → Pi | Mac 光驱接头/桥接兼容性，USB 供电峰值 | 识别、读 CD-DA、退盘、连续播放 |
| Pi → 屏幕 | Pi 4B USB-C 不输出 DP 视频；HDMI 显示板接口不明 | HDMI 输出、分辨率、供电、触摸输入 |
| Pi → DAC | 音频默认设备漂移、电源噪声 | 重启后固定路由、噪声、采样率 |
| DAC → RCA/功放 | 线路电平、音量、阻抗、地环路 | 双输出及静音顺序 |
| Pi → SSD | USB 带宽/设备竞争/电源 | 同时视频播放、光驱读取、文件拷贝 |
| Pi → 控件 | GPIO 电平与机械消抖 | 安全关机、旋钮与按钮测试 |
