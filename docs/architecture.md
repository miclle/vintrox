# VINTROX One 总体系统架构

**状态：2026-10-16 更新的设计基线，未通过整机验证。**

## 1. 架构目标

继续复用已有 Raspberry Pi 4B承担计算、存储管理、网络和界面，将光驱、屏幕、DAC、功放、扬声器设计成可独立测试及更换的模块。

## 2. 系统方框图

| 源/控制 | 连接 | 目的与职责 |
| --- | --- | --- |
| UJ-898 | 匹配接口的 USB 桥接 | Pi 读取 CD-DA，控制播放与退碟 |
| 移动硬盘 | USB，按供电需要接有源 Hub | Pi 管理本地音视频 |
| 实体控件 | GPIO 或 USB 控制器 | 音量、播放、退碟、安全关机 |
| Pi | micro-HDMI → HDMI 驱动板 | 屏幕显示，电源独立分配 |
| Pi | USB 或 I²S → DAC | 音频转换为双声道线路信号 |
| DAC | 分配/缓冲/静音 | RCA Line Out 与内置双声道功放 |
| 功放 | L/R 独立扬声器接线 | 每声道 4Ω/10W 音箱，向机身两侧发声 |
| PD/电池电源系统 | 分路稳压 | Pi、USB 外设、屏幕、功放和控制 |


表中的 DAC 信号分支**不代表直接 Y 线分接已被验证**。需要根据 DAC 驱动能力、阻抗、静音和音量要求决定缓冲、音频分配或切换电路。

## 3. 关键数据流

### 音乐 CD

`光驱 → USB 光驱桥接 → Linux 光盘子系统 → CD-DA 读取 → 播放软件 → 音频系统 → DAC → 功放/RCA`

- CD-DA 通常不作为普通文件系统直接打开；应由支持音频 CD 的播放器/库访问。
- 退盘优先使用软件命令及驱动器支持的机制，前面板按钮是后续控制入口。
- 应测试部分老盘、无曲目元数据的情况；脱离网络仍能播放。

### 本地音视频

`移动硬盘 → Linux 文件系统 → 媒体播放器 → 视频解码/HDMI + 音频/DAC`

若操作系统默认将声音送到 HDMI，必须明确把音频路由至独立 DAC；屏幕仅承担视频显示，不依赖它的模拟音频输出。

### 普通应用

`Linux → 桌面环境/应用启动器 → 浏览器、文件管理器、其他 ARM Linux 应用`

建议早期保留标准桌面，以免定制 UI 阻碍调试；待功能稳定后叠加播放器式主界面。

## 4. 软件分层（建议）

| 层 | 职责 | 候选技术 |
| --- | --- | --- |
| OS | USB、网络、文件系统、设备驱动 | Raspberry Pi OS / 兼容 ARM64 Linux |
| 音频 | 音频路由、设备选择、音量 | ALSA + PipeWire（需选定系统版本验证） |
| 播放引擎 | CD、音乐、视频 | 支持 CD-DA 的库/播放器；mpv/VLC 等候选 |
| 服务层 | 媒体库、设备发现、按键映射、状态管理 | 本地服务；具体语言与进程边界待定 |
| UI | 主页、媒体库、设置、应用入口 | Web UI / Qt 等候选，暂不锁定 |
| 运维 | 日志、设备诊断、升级、安全关机 | systemd、日志工具等 |

可先使用成熟播放器完成闭环，确认接口后再开发定制 UI，不强制从零编写解码器。

## 5. 电源与接地概念

用户确认内置电池及单一 Type-C 电源输入。优先候选为 USB-C PD + 匹配充电/电源路径管理 + 受保护电池 + 分路稳压，详见 [电源与电池](power-system.md)。内部不限定只有 5V，屏幕和功放按实际需要供电。

外部输入拔插不中断运行、低电量安全关机、关机后切主要负载是设计目标；具体电路和切换效果待测。普通充电宝“边充边放”、PD 诱骗板或保护板不能单独证明满足这些目标。

不得把不同电压简单并联。功率回流、信号地与机箱连接需经噪声测试；BTL 扬声器输出不能引出 RCA 或将负端接地。外设供电须检查 USB 倒灌及启动压降。

## 6. 接口风险

| 接口 | 主要风险 | 先行验证 |
| --- | --- | --- |
| 光驱 → Pi | Mac 光驱接头/桥接兼容性，USB 供电峰值 | 识别、读 CD-DA、退盘、连续播放 |
| Pi → 屏幕 | Pi 4B USB-C 不输出 DP 视频；现有 HDMI 输入尚未与 Pi 联调 | HDMI 输出、分辨率、供电、触摸输入 |
| Pi → DAC | 音频默认设备漂移、电源噪声 | 重启后固定路由、噪声、采样率 |
| DAC → RCA/功放 | 线路电平、音量、阻抗、地环路 | 双输出及静音顺序 |
| Pi → 移动硬盘 | USB 带宽/设备竞争/电源 | 同时视频播放、光驱读取、文件拷贝 |
| Pi → 控件 | GPIO 电平与机械消抖 | 安全关机、旋钮与按钮测试 |

## 7. 下一步

先做不带机箱的功能样机，收集实测接口和尺寸资料，再设计电源 PCB/线束与外壳；详见 [路线图](roadmap.md) 和 [决策记录](decisions.md)。

## 8. 结构约束

屏幕决定正面宽度，左右音箱置于机身两侧向外发声。光驱优先竖装屏幕后方、顶部进碟，先测试可靠性；电池优先下置。空间冲突须在临时机架解决，不能凭逻辑连接表认为零件已经能装下。
