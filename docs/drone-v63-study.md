# VINTROX Drone v63 外观研究

2026-10-31 建立 v63 屏幕外框候选，目标是继续贴近 `references/alexander-shevchuk-drone` 的图片和 `video-cam.mp4`，同时保留四根新增支柱及参考中可见的外挂筒、屏幕侧控件和格栅。

候选仅修改 `ScreenBezel` 和 `BezelLip` 的真实 BRep 外框，实测平面屏 `210×160×2 mm`、可视区 `200×150 mm`、外挂筒、侧控件、格栅和支柱均保持。候选 FCStd、STEP、网格绑定、保存读回、独立 STEP 读回、渲染、固定相机、50% 叠加和差异图集中在 [`v63-screen-bezel-study-3`](../cad/drone-concept/comparison/v63-screen-bezel-study-3/)。

视频十方位平均轮廓 IoU 为 **85.45204%**，正式 v61 为 **85.49202%**，下降 0.03998 个百分点；静态七图为 **82.23131%**，正式 v61 为 **82.22682%**，上升 0.00449 个百分点。视频整圈退步，因此候选不替换正式 v61。

比较使用保存 CAD 的真实网格和校准相机投影；没有图像非刚性变形、拉伸、逐部件对齐或忽略部件。屏幕曲率、黑色材料与背景分割仍有不确定性，结果只用于外观轮廓研究，不代表完全一致、制造、装配、光学或实物验收。
