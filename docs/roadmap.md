# 实施路线图

以**分阶段、可验证、可回退**为原则。每一阶段结束后将测试结果和设计决策更新到文档。电源和电池占位应在 M1/M2 期间提前评估，不能等最终机箱定型后才加入。时间表暂不设固定日期，避免在关键兼容性尚未确认时做虚假承诺。

**测绘资料进展（2026-10-18）**：已整理光驱本体三向及与 USB 转接器插接后的组合测量照片，读数和边界统一见 [测绘记录](validation.md#16-光驱与-usb-转接器照片测绘记录)。型号铭牌、最大外形、接口针脚和供电仍未补齐；M0 资产登记及 M1 运行验收项保持未完成。

已补充屏幕及背面右侧排线电路板的[用户测量口述](validation.md#17-屏幕与背面排线电路板测量口述)，高度已更正为160mm，排线板高度由上下间距推导；可视区按用户指定200 × 150mm建模；型号、固定方式和排线组合净空仍待补，不勾选M1显示验收。

## M1 — 核心旧硬件互通（最高优先级）

- [ ] 确认 MATSHITA UJ-898 接口、桥接适配及供电。
- [ ] 在临时支架验证 UJ-898 入口朝上的竖装吸入、播放与退盘。
- [ ] 用 Pi/Linux 读取 CD-DA 并完成播放、暂停、跳曲、退盘。
- [ ] 核实 iPad 屏幕驱动板的实际输入与供电规格。
- [ ] 完成屏幕显示、分辨率和输入交互验证。
- [ ] 移动硬盘稳定挂载与光驱并发访问。

**阶段观察（2026-10-17）**：用户发现 USB DVD 光驱在 GNOME Disks 中反复掉线/重新出现，Y 型 USB 线补充供电后能读取光盘。仍需记录桥接器与供电来源，并完成 CD-DA 全流程、竖装和 USB 并发测试；上述验收项暂不勾选。操作见 [USB 光驱文档](usb-optical-drive.md)。

**方案细化（2026-10-18，非测试进展）**：按 [电源设计](power-system.md) 优先搭建 Pi 单独供电＋有源 Hub 台架；单口不足时评估自供电桥接器/独立 5V 分路。[验证清单](validation.md) U-01～U-07 细化接线、防反灌、启动压降、并发和温升，U-08 留待 PD/电池集成后执行。示例预算不是实测，M1/M4 验收项不勾选。

**完成条件**：桌面无机箱样机可以读取 CD，并在目标屏幕上操作，且不因供电不足重启。

**概念建模进展（2026-10-18）**：已生成 [参数化布局与外观/内部预览](layout-model.md)，第三版沿用第二版压缩至 160mm 的木壳深度，增加圆润木壳、内嵌黑框和 12mm 内缩底座，随后同步屏幕210 × 160 × 2mm及用户指定200 × 150mm可视区，木壳派生为234 × 212 × 160mm，新增背面排线板，其余12个包络三边保留；单箱增厚5mm与硬盘碰撞的边界已记录。保留侧向发声和顶部进碟候选，完成静态干涉、线束区、可视区遮挡、槽口对齐检查与保存读回。尚未完成全套实物测绘或制作临时机架/打印结构件；M4 相关验收项保持未完成。

## 风险与优先级

| 风险 | 影响 | 缓解方式 |
| --- | --- | --- |
| 旧光驱接口不兼容或供电不足 | 阻断 CD 功能 | M1 最先处理，保留替代 USB 光驱方案 |
| 屏幕 HDMI 联调或独立供电不稳定 | 阻断显示及电源集成 | 已确认有 HDMI 输入，先记录板号及供电规格并联调 |
| Pi 性能无法满足目标 App/视频 | 体验不佳 | 先跑软件负载测试，架构允许升级主控 |
| 功放输出/音频地错误 | 有安全或设备损坏风险 | 严格区分扬声器端与线路端，低电平先测 |
| 内置扬声器影响光驱 | 跳读与共振 | 独立声学腔体及防振托架 |
| 机箱开孔过早 | 浪费木材和时间 | 完成测绘与临时机架验证后再加工 |

具体顺序、依赖与首轮交付见 [执行优先级与依赖](validation.md#执行优先级与依赖)；尺寸、额定值和证据填写在同一文件的 [测绘表](validation.md#1-测绘表)。本路线图只跟踪阶段，不复制测量字段、测试条件或增加第二套验收编号。

当前先引用已取得的 [Pi 官方名义尺寸](validation.md#14-pi-4b-官方名义尺寸)，取得屏幕背面型号与驱动板丝印后查匹配资料，并完成其余实物身份与粗测；建立稳定的光驱水平对照后再验证顶部进碟。屏幕 HDMI 联调与音箱结构检查可并行。随后推进临时布局、USB 并发、音频及功耗测量，最后集成 PD/电池系统。候选电池和电源模块的占位仍在 M1/M2 期间提前评估。

测试通过后更新决策状态、BOM 和机箱设计；最终开孔只依据实测图纸。
