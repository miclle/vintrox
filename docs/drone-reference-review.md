## 零件体积与分层原则

- 大形：连续主壳、前罩、后部喷口和四光轴决定轮廓；侧/背甲片提供可见厚度，避免所有面处于同一平面。
- 中形：翼板冠形面与内侧纵脊、分瓣侧环、后部护甲、顶部检修板形成台阶及投影。
- 小形：压框、肩环、扣片、根铰、螺钉和凹槽提供连接关系。它们是外观实体，未确定真实紧固件规格、工具净空或受力路径。
- 屏幕图案与表面色条按显示/涂装示意处理；实体封闭检查不能证明每个图形都应单独打印。
