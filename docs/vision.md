# 愿景与产品定位

> VINTROX — 一体式媒体电脑
>
> 当前外形方向：科技、现代、个性；外壳与固定结构3D打印。

2026-10-18 后续修订：尽量还原 [Drone 参考](../references/alexander-shevchuk-drone/README.md)的完整造型，以屏幕尺寸调整整体比例；造型优先、音质可让步，背面喷口增加低音单元。该方向替代此前最小宽度与终端外形选择；木制材料仍不采用。已有[独立外形草模](drone-concept.md)与低音假设占位，2.1 未选型或实测。

## 1. 为什么做 VINTROX？

最初的想法是把一台 2010 年前后 MacBook Pro 的旧光驱变成独立 CD 播放器，并复用已有的 iPad 拆机改装屏。随着需求延伸，设备不再只是播放 CD：它还应读取本地存储的音视频、联网、运行应用，并保留桌面计算机的自由度。

传统 Hi-Fi 强调实体操作和机械仪式感，Mini PC 强调通用性；VINTROX 想在两者之间建立自己的形态：**拥有真实光驱的一体式媒体电脑**。

## 2. 核心定位

- **品类**：一体式媒体电脑，不是单一 CD Player。
- **设备形态**：适合桌面、书房、影音角的带屏幕、音响和光驱的一体化设备。
- **交互气质**：清晰的功能分区、现代仪器感、旋钮和按键的操作反馈；造型个性由分层结构与可维护模块体现。
- **计算能力**：依托 Linux，可联网、打开媒体软件、管理文件并运行一般应用。
- **硬件价值**：复用既有硬件，设计开放、结构可维护、功能可扩展。

## 3. 目标体验

1. 按下实体电源控制，看到简洁、优雅的启动界面。
2. 放入 CD，设备识别光盘，显示曲目列表并允许直接播放；没有网络时也能正常工作。
3. 从本地移动硬盘 浏览专辑、歌曲或视频，并通过屏幕播放或外接音频系统聆听。
4. 通过屏幕界面和少量实体旋钮/按键（触摸功能待确认）完成最常用操作；需要时切换到 Linux 桌面运行应用。
5. 通过内置左右扬声器使用，也可以通过 RCA 接入外部有源音响或功放。

## 4. 设计原则

### 体验与外观

- 实体控制承担常用操作，屏幕负责浏览、显示和高级操作；触摸功能尚未确认，应保留替代输入。
- 外形体现科技、现代、个性，保持稳定、流畅、可维护的使用体验。
- 外壳和内部固定结构采用3D打印，按制造与维护需要组织分件；不采用木制材料。
- 控制灯光亮度、机械噪声和散热噪声，避免喧宾夺主。

### 工程与软件

- 标准化音频输出，RCA 必须是 Line Out 而不是扬声器放大输出。
- 优先验证旧光驱、旧屏幕等不可替代部件的实际兼容性。
- 保留通用 Linux 系统功能，不将 VINTROX 锁定为封闭固件。
- 优先模块化、可维修、可迭代，先桌面功能样机再定型机箱。

## 5. 第一代边界

VINTROX One 的第一目标是完成**可靠的 CD + 本地媒体 + 屏幕 + 网络 + 应用 + 双音频输出 + 电池 + Type-C 电源输入**的一体化原型。

暂不把高解析度流媒体服务兼容性、DRM 视频平台、特定商业 App 的 ARM 适配、CD 抓轨、无线投屏、遥控 App、外部 HDMI 显示器输出等视为必定交付的第一阶段功能；可以作为后续候选项。

## 6. 品牌与产品命名

- **VINTROX**：项目与产品系列名。
- **VINTROX One**：第一代集成原型（工作名称）。
- 原“Retro Media Computer / Vintage Soul. Modern Mind.”和“Walnut Edition”为已撤销的风格描述；新英文口号尚未确定。

## 7. 如何定义成功？

- 不靠外接电脑即可从光驱读取并播放标准音乐 CD。
- 屏幕和内置扬声器组成完整的独立体验，RCA 可接入外部音响。
- 使用内置固定的移动硬盘时可以浏览并播放本地常见格式的音视频（具体支持以软件/解码测试矩阵为准）。
- 网络连接、文件管理和安装/运行兼容 Linux 应用可行。
- 整机有安全的供电结构、合适的散热、可以拆开维修的机箱。

## 8. 当前收敛方向（2026-10-18修订）

- 电池供电属于整机需求，支持脱离外部电源使用。
- 3D 打印外壳和内部固定结构，以屏幕尺寸确定 Drone 参考比例，允许翼板、提手与外挂件增加总包络；不采用正面“左音箱—屏幕—右音箱”布局。
- 左右音响朝机身侧面发声，背面朝后下方的大喷口新增低音单元；屏幕后方顶部垂直进 CD 是候选布局，需先验证。
- 设备是可移动使用的桌面一体机；续航与体积应共同权衡，暂不承诺固定尺寸或续航。

最新参考及设计边界见[机箱设计](enclosure.md#9-drone-外形还原与背面低音)。新增低音形成内置 2.1 目标；媒体、计算、外部双声道 RCA、电池及单一 USB-C 入口继续有效。
