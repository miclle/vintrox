## 使用与补充

- 文件名采用小写英文和连字符，描述“部件＋视图/用途”；仅在型号可确认后加入型号，避免把未知商品图命名为已确认硬件。
- 每类目录的 README 记录图片内容、来源线索和待核对项。光驱、USB 转接器和音箱均已补充用户提供的淘宝购买链接，转接器和音箱另有 SKU；各部件完整型号及所选规格仍待核对。水印仅作来源线索，不作为身份依据。
- 屏幕/驱动板、Pi、移动硬盘、DAC/功放、电池/PD/配电等尚无本地图片资料；后续有实际资料再建目录，不以缺图推断项目没有该部件。
- 新资料注明来源链接（如有）、获取日期、型号/版本及信息状态；实物照片与商品图片分别标明，测量条件和结果记入 [验证清单](../docs/validation.md)。
- 选型与资产状态以 [硬件清单](../docs/hardware.md)、[设计决策](../docs/decisions.md) 为准；测试顺序见 [路线图](../docs/roadmap.md)。本次归档不改变 BOM、设计决策或验收状态。
