## 使用边界

官方图可用于布局和支架草模；部件公差、实物版本、实际散热器、板底突出物、连接器与线缆占位仍需核对。图纸中的器件高度不等于带散热器和线缆的完整装配高度；不得只用 PCB 板框尺寸冻结安装空间或加工尺寸。

现有概念 CAD 的 Pi 区域为综合占位包络，继续按 [布局模型说明](../../docs/layout-model.md) 标注为假设；裸板名义尺寸的取得不自动证明该包络足够或完成实物装配。
