# VINTROX

**一体式媒体电脑**

VINTROX 是一台带实体 CD 光驱、iPad 改装屏、树莓派、移动硬盘、内置立体声音响和电池的一体式媒体电脑。它既能播放 CD 和本地音视频，也能联网、运行兼容的 Linux 应用。

第一代原型工作名称为 **VINTROX One**。最新外观目标为尽量还原 [Alexander Shevchuk Drone 参考](references/alexander-shevchuk-drone/README.md)，以显示屏尺寸调整整体比例，**造型优先，音质允许让步**。背面朝后下方的大喷口规划新增一个低音单元，与侧向 L/R 组成内置 2.1 目标。外壳和内部固定结构均采用 **3D 打印**，不采用木制材料；整体尺寸可为参考造型调整，替代原宽度优先规则。

已建立独立的 [Drone 外形评审草模](docs/drone-concept.md)，包含前罩、提手、翼板、侧面模块及背面喷口低音占位，并输出真实 CAD 几何渲染。**未打印、未实物装配，低音单元/功放未选型**。先前 `vintrox-terminal` 保留作布局资料，其预览和验证不代表新设计。

2026-10-24 推进至 v53 [逐图与整圈叠加修订](docs/drone-overlay-comparison.md)：收薄侧后方底壳，露出底部环件和线束；四支柱与中央连接条带不变。固定十方位轮廓 IoU 84.88%→85.03%，90% 目标未达，保留全部退步视角。见[同角度对照](cad/drone-concept/comparison/rear-belly-study/README.md)。

2026-10-26 后壳折角跟进至 v58：后壳斜折段半径 24mm，凹舱继续按独立阴影内衬处理，四根支柱保持不变；固定相机视频/静态轮廓均有小幅变化，仍是外观研究，见[后壳叠加板](cad/drone-concept/comparison/v58-rear-followup-study/README.md)。

底部支撑按 2026-10-22 用户要求改为从中央向四角斜下伸出的四根细光轴，抬高机身；Ø6mm 轴径与高度为外观假设，固定和稳定性未实测，见 [支撑方案](docs/enclosure.md#底部中央四光轴支撑2026-10-22)。

## 布局与电源的约束

- 正面以屏幕为比例起点，优先还原前罩、提手、翼板、侧面圆环与喷口；允许整体包络为造型增加。
- 两个音箱位于屏幕后方的左右侧，利用深度布置；不是在屏幕两旁增加正面扬声器区域。
- 屏幕后竖直光驱、顶部吸入式进碟是当前优先验证布局，尚未确认 UJ-898 竖装可靠性。
- 最新外观参考为本地 Drone 素材，新增背面低音的边界见[机箱设计](docs/enclosure.md#9-drone-外形还原与背面低音)；先前分层桌面设备参考保留为原终端模型来源。
- 现有 `vintrox-terminal` 本体234 × 212 × 160mm，含脚/控件总包络234 × 217 × 170mm，均为原草案参数派生，不约束新造型，不作为最终尺寸或打印通过结论。
- 不冻结外形尺寸。早期约 270 × 210 × 170mm 的草案已撤销，不得用于加工。
- Type-C 是外部接口要求，不要求整机只用 5V；PD 档位、电池和转换电路必须匹配。
- 插拔外部电源时不中断运行是设计目标；普通“边充边放”充电宝不等于已验证的 UPS。

## 开发原则

复用已有硬件，先完成接口与功耗测试，再确定电池和机箱。商品标称值、用户确认信息和整机实测结论分别记录；不把峰值功率当成持续功率，不把推算尺寸当成加工尺寸。优先标准接口、可拆卸模块和可维护结构。
