# VINTROX

**Retro Media Computer — Vintage Soul. Modern Mind.**

VINTROX 是一个将复古 Hi-Fi 设备的物理质感与现代计算机能力融合在一起的开源 DIY 项目。它不是一台只能播放 CD 的机器，而是一台**带实体光驱、屏幕、独立音频系统和网络能力的桌面多媒体计算机**。

第一代原型暂称 **VINTROX One**，计划采用黑胡桃木与金属面板的复古造型，同时保留可扩展、可维修的计算机内部架构。

> 当前阶段：概念与系统设计（Concept / Design）。本文档描述目标与候选方案，不代表硬件已经完成集成验证。

## 想实现什么？

- **实体媒介**：插入音乐 CD，直观地浏览并播放曲目。
- **本地影音**：从 SSD 等本地存储播放音乐和视频，管理媒体资料。
- **真正的计算机**：联网、浏览网页、运行 Linux 应用，不限制为封闭播放器系统。
- **完整的声音链路**：内置左右扬声器，同时提供外部 RCA 线路音频输出。
- **触觉与审美**：实体按键/旋钮、10 英寸级屏幕、黑胡桃木装饰、金属前面板。
- **可持续演进**：模块化硬件，方便替换光驱、屏幕、主板、音频与软件。

## VINTROX One：设计基线

| 子系统 | 当前方向 | 状态 |
| --- | --- | --- |
| 计算平台 | Raspberry Pi 4B | 暂定主控 |
| 光驱 | MacBook Pro (13-inch, Mid 2010) 拆机 MATSHITA DVD-R UJ-898 | 已有设备；外接适配待验证 |
| 屏幕 | 约 10.2 英寸 iPad 拆机屏 + 改装显示驱动板 | 已有设备；实际输入与供电待确认 |
| 本地存储 | USB SSD | 暂定 |
| 音频 | 独立 USB/I²S DAC + 双声道功放 | 方案待选型 |
| 输出 | 内置左右扬声器 + 立体声 RCA Line Out | 核心要求 |
| 外观 | 黑胡桃木 + 金属构件 + 3D 打印内部支架 | 设计方向 |
| 系统 | Linux + 可切换到通用桌面的媒体界面 | 软件架构待定 |

**注意**：屏幕如果通过 USB-C 接收视频和供电，不意味着 Raspberry Pi 4B 的 USB-C 供电口能输出视频。必须依据现有屏幕驱动板的真实接口，验证 micro-HDMI → HDMI/转换器的连接方案。光驱也需核实接口及 5V 供电、退盘控制。

## 开发原则

- 先验证能否真实连接、稳定工作，再设计不可逆的机箱开孔。
- 区分「已有」「候选」「待测」「已验证」，不把商品页的宣传功率当作实测输出。
- 不牺牲基本的 Linux 计算机能力来换取封闭的播放器界面。
- 优先采用可替换模块和标准接口，避免把光驱、屏幕、功放永久绑定到单一平台。
- 外置认证电源优先；低压布线注意保护、隔离、接地和热管理。
