# VINTROX

**Retro Media Computer — Vintage Soul. Modern Mind.**

VINTROX 是一台带实体 CD 光驱、iPad 改装屏、树莓派、移动硬盘、内置立体声音响和电池的复古一体式媒体电脑。它既能播放 CD 和本地音视频，也能联网、运行兼容的 Linux 应用。

第一代原型工作名称为 **VINTROX One**。外观采用复古木制风格，黑胡桃木是优先方向；整机尽可能小，尤其优先压缩宽度。

> 设计基线更新：2026-10-16；USB 光驱现场观察补充：2026-10-17。文档区分用户确认、候选方案和待实测项；当前没有完成整机集成验证。

## 布局与电源的约束

- 正面以屏幕为主；两侧只允许必要边框及少量开关/旋钮，优先将控件放在下边框或机身侧面。
- 两个音箱位于屏幕后方的左右侧，利用深度布置；不是在屏幕两旁增加正面扬声器区域。
- 屏幕后竖直光驱、顶部吸入式进碟是当前优先验证布局，尚未确认 UJ-898 竖装可靠性。
- 不冻结外形尺寸。早期约 270 × 210 × 170mm 的草案已撤销，不得用于加工。
- Type-C 是外部接口要求，不要求整机只用 5V；PD 档位、电池和转换电路必须匹配。
- 插拔外部电源时不中断运行是设计目标；普通“边充边放”充电宝不等于已验证的 UPS。

## 开发原则

复用已有硬件，先完成接口与功耗测试，再确定电池和机箱。商品标称值、用户确认信息和整机实测结论分别记录；不把峰值功率当成持续功率，不把推算尺寸当成加工尺寸。优先标准接口、可拆卸模块和可维护结构。
