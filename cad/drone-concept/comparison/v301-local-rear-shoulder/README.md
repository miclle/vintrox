# v301 后肩局部恢复宽度

v300 在静态第 03 图少覆盖 496 个参考前景像素。对这些像素发射固定相机射线，489 条击中 v292 的后肩网格，其中 455 条位于 Y<230 mm。视频第 150 帧因后肩收窄而减少的 275 个整机遮罩像素中，270 条射线击中同一组网格，其中 234 条位于 Y=240–250 mm。用这两处投影差异选取候选接续位置。[静态第 03 图差异近景](still-03-lost-outline.png) · [射线交点](shoulder-rays.json)

将 v292 较宽的后肩前段与 v300 较窄的后段融合，分别在 Y=225、230、240 mm 接续。另在 Y=234 mm 附近用斜切面混合。四档的两个保存形体均为有效闭合单实体，通过高级几何检查，原有接触均保留。Y=230 mm 档与两侧内背板原有约 10.715 mm 间隙增加约 0.0014 mm。[225 mm 几何](local225/geometry.json) · [230 mm 几何](local230/geometry.json) · [240 mm 几何](local240/geometry.json) · [斜切几何](taper234/geometry.json)

在 FreeCAD Python 环境运行 `replay-plane.py` 或 `replay-taper.py`。将 v300 FCStd 与重建网格传给 `--base` 和 `--mesh`，将 v292 FCStd 传给 `--wide`。提供空的 `--out` 目录，`--transition` 使用上述 Y 坐标。通过 `PYTHONPATH` 加入仓库的 `tools`，输出模型使用 v300 的固定相机渲染。[v300 网格与相机](../v300-rear-shoulder-nozzle/README.md)
