# v391 底部回环侧向弧段

在 v388 上加入第 30、90 帧的 19 个可见中心线样点，沿用第 60、120、180 帧的标注。使用完整相邻零件的网格，在这五个固定视频方位求各像素的遮挡深度，约束两条镜像中心线。两端固定，中段半径取 4.4 mm，端部半径取 2.2 mm。三组初值求解后，选择残差平方和最低的一组。半径、镜像及被遮住的路径均为外观假设。[拟合输入及输出](fit.json) · [保存读回、端部接合和支柱间隙](readback.json)

第 30 帧新增的七个中心样点到完整模型中可见回环的最大距离由 8.06 降至 1.41 px，第 90 帧十二个点由 20.62 降至 16.03 px。第 210 帧的七点单独用于检查，由 12.00 增至 13.93 px，仅一个样点落入可见回环。这组距离测到回环的可见面积，统计值受管径影响。[近景，左起为参考、v388、v391](side-views.jpg) · [逐点归属统计](centres-check.json)

沿既有可见边缘另外复测，第 90 帧 RMS 从 17.43 降至 10.97 px，但第 180 帧右侧最大偏差从投影屏宽的 5.82% 增至 22.15%。第 150 帧右侧最大偏差从 5.94% 增至 6.56%。冻结相机的十方位视频、静态七图与拼图十格平均 IoU 分别为 85.92697%、82.53062%、89.84595%，三组均低于 v388。保留 v388 为正式版。[可见边缘](edges.json) · [视频](video.json) · [静态](still.json) · [拼图](sheet.json)
