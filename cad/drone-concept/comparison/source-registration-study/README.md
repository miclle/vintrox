# v47 喷口根部与后壳过渡联动

2026-10-24，采用 `root-profile-clearance`，在固定相机下重建金色过渡壳、根部卷边、12 片叶片及其附属件、内喉管和内锥面，共 126 个对象（含两处灯角让位）。四根支柱、实际屏幕、后壳凹舱内衬和框架保持。凹舱暗部仍是空间与遮挡产生的阴影，没有增加包围喷口的筒壁。

## 本轮取舍

原先根环只用视频第 60、120、180 帧的 23 个观察点约束；补充第 90、150 帧后，总计五视角 45 点。根环中心向机身方向移动约 8.72mm、高度降低约 2.39mm，半径增大约 1.20mm，轴倾角微调约 0.34°。出口圆的位置、半径 43.6mm 与倾斜保持；金色壳、叶片内外层与贴片一起跟随，以免只改外皮产生交叠。所有尺寸为外观重建假设，不是加工尺寸。

保存模型的五视角根环 RMS **5.117→3.636px**。第 60、120 帧有退步，第 90、150 帧改善；不删去不利观察。原始拟合与当前保存读回见 [五视角拟合](five-video-root-fit.json)和[保存根环检查](../nozzle-root-check.json)。另行多起点最近曲线拟合得到略不同的根环，RMS 3.463px，支持向机身回收的方向但表明重建并不唯一，见[独立复算](five-video-root-reproduction.json)。没有据此反复调整模型追逐稀疏手工点。

导轨角间距从局部 4.9° 调到 5.4°（构造中还乘节距比例）。第 120 帧第 590 行的共同可见导轨组从 7/9 变成 8/9；当前两组间距 RMS 0.707px，但样本已经变化，**不能与 v46 的 0.791px 直接宣称改善**。共同可比的第 9 组间距当前为 12px，与手工参考一致；第 7 组一根导轨被遮挡。参考亮边与几何中心约有 ±2px 人工观察不确定性。

## 灯角交叠修正

初版根部试件与左右下灯角各交叠约 13.94mm³，接触检查未通过。保留[失败记录](root-profile-g54/formal-emitter-failure.json)。现沿用原灯框分件逻辑，将灯角端部裁到新喷口外包络之外，约留 0.3mm 曲面扩展量；只有这两个灯角随动，其余灯条和反射件保持，重新执行全部固定相机比较和接触检查。没有放宽交叠阈值。

## 相机诊断与边界

曾测试根环参与的静态相机重配准：根环误差下降，但其它标志点误差上升，七图总轮廓没有改善，因此未采用。`diagnostic-cameras.json`、`joint-root/diagnostic-cameras.json` 和 `diagnostic-renders/` 只是诊断；正式视频及静态相机哈希均保持。

`root-holdout.json` 中两帧只相对于先前的三视频/静态联合拟合是留出样本；在五视频拟合里已被使用，不能再称独立验证。`five-video-root-fit.json` 为建模时参数记录；`five-video-root-reproduction.json` 为另行最近曲线多起点复算，不伪称逐位复现原优化路径。

- 126 个改动件的生产源码、候选和正式保存几何双向差集小于 `1e-6mm³`，有效单一闭合实体，高级 BOP 检查通过。
- 572 个其它带形体对象保持；四支柱实体差集为零。572 个原 BRep 和 GUI 数据原样转移，570 个其它可见网格及材质保持。
