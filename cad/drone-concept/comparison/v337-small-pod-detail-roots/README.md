# v337 小喷口细节根部接续

承接 v336 的 7 mm 小喷口口沿。先将 108 件 LowerPodEdgeRail 和 LowerPodPetalRidge 在局部 Z=42.5 mm 以下截除，再沿径向向内做根部仿射接续。最终 16 件脊条与口环的原有接触保持，所有 108 件细节与对应叶片的间隙均未扩大。保存形体均为有效闭合实体，未新增高级几何错误。[根部检查](trim.json)

| 固定相机平均 IoU | v335 | v336 7 mm | v337 |
| --- | ---: | ---: | ---: |
| 视频十方位 | 86.01661% | 86.00049% | 86.00473% |
| 静态七图 | 82.60498% | 82.56578% | 82.56817% |
| 拼图十格 | 89.87424% | 89.85453% | 89.85891% |

细节根部修订使视频均值相对 v336 小幅回升，静态和拼图也回升，但仍低于 v335。第 60、180 帧的口沿局部 RMS 为 2.68 和 2.55 px，原四帧的口沿最大偏差均低于屏宽 5%。第 30、210 帧新口沿标注仍分别为 9.17% 和 7.65%，说明斜视安装和外罩整体边界仍需单独优化。[口沿与叶片端缘](visible-pod-loop-edges.json) · [逐片端缘](terminal.json) · [视频](video.json)

正式模型继续采用 v335。v337 试验确认了可执行的细节根部接续方式，后续可沿第 30、210 帧的外罩安装姿态筛选小范围整体旋转与平移。复现时在 FreeCAD Python 中运行本页同名 trim.py，以 v336 7 mm 候选为 base，传入 root 42.5 和 seat-ridges shear。
