# v377 喷口叶片端角的三维定位

在第 60、90、180 帧各取一个可以连续追踪的折边端角。沿正式视频相机轨道，每个视频帧绕固定目标转 −1.2°，用九幅原图中的坐标最小化同一空间点的重投影残差。第 180 帧端角的估计坐标为 (29.64, 232.83, 55.83) mm。分别对前五帧、后五帧拟合，两解相距 0.75 mm。将同一端角的像素跟踪延长到 32 帧，两半段拟合相距 5.4 mm，反映了纹理跟踪与相机误差。这里的 mm 采用模型坐标系及屏幕尺度。[九帧拟合](triangulation.json) · [六个邻近点的连续跟踪](rim-tracks.json)

在 v375 喷口局部 Z = 107 mm 处接续第 0、4 号镜像叶片。第 0 号叶片与附件沿局部 X、Y、Z 的附加位移分别为原轴向超出量的 −0.5730、0.1325、3.0617 倍，第 4 号反转 X 分量。105 mm 接续面穿过导轨并造成新增高级几何错误，改用 107 mm 后通过改动件的实体和高级几何检查。120 处邻件距离已复测。[完整参数与对象](geometry.json) · [邻件间距](contacts.json)

第 180 帧端角距可见叶片边缘从 29.53 px 降到 1 px，整组历史采样峰值从投影屏宽的 21.94% 降到 14.21%。第 60 帧的历史峰值从 20.96% 降到 8.35%，第 90 帧从 8.85% 降到 6.13%。第 60 帧的最近 CAD 对象从第 5 号折边变为第 0 号叶片，存在对应关系歧义。近景中延长的两片突出于相邻叶片，参考中的末缘更连续。[三处近景](tracked.jpg) · [所有原标注](visible-components.json)
