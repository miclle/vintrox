# v275 前罩上缘局部修整

从 v272 保存模型出发，将静态第 05 图归因到前罩主体的外溢像素沿固定相机射线回查。新露出的上缘位于 Z≈235–246 mm，原有前端外溢延伸至 Z≈191–233 mm。射线命中用于定位实体，分割、遮挡和相机误差仍会影响像素归因。[射线命中数据](ray-samples.json)

本轮用镜像放样刀具切削前罩主体两侧上缘，保存后仍为单一有效闭合实体，减少约 2,753 mm³。六组邻件接合距离均为零，原有高级检查错误集合保持。STEP 独立读回和原生显示复查留在正式交付阶段。[几何与接合](trim-check.json)
