# v233/v234 扬声器整体边界筛选

本轮以正式 v229 `candidate.FCStd` 为基线，使用真实 CAD 对称重建左右扬声器的外口压圈、细压边、悬边、锥盆、中心件和轮毂颈部。v233 将这些对象统一收缩到 0.995 倍，v234 统一放大到 1.005 倍。屏幕、外挂筒、屏幕侧控件、格栅和四根支柱保持。

两组候选均完成保存 FCStd、STEP、696 个可见对象和固定视频十方位渲染。v233 另完成七张静态图复核。相机、参考视频、CAD 分割和评分规则与 v229 完全相同，没有图像变形、逐件配准或省略可见零件。

| 候选 | 视频十方位平均 IoU | 相对 v229 | 结论 |
| --- | ---: | ---: | --- |
| v233，扬声器整体 0.995 倍 | 85.9158337% | +0.0000679 个百分点 | 保留 v229 |
| v233 静态七图 | 82.5349737% | −0.0000629 个百分点 | 保留 v229 |
| v234，扬声器整体 1.005 倍 | 85.9151160% | −0.0006418 个百分点 | 保留 v229 |

增益处于渲染与三角化噪声量级，且只完成视频筛选。两组候选不替换正式模型，也不能据此宣称 90% 整圈 IoU 或主要部件 5% 轮廓目标完成。扬声器尺寸仍是外观假设，未完成制造、装配、声学、热、电气和实物验证。
