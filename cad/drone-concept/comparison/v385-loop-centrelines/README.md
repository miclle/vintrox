# v385 底部回环中心线

视频第 60、120 和 180 帧中可见两侧底部回环的内外缘。取可辨认弧段的管壁中间位置作为中心线估计。在 v384 上固定四个根部，采用镜像 B 样条及三个平滑正弦分量调节其余站点。管中段半径按参考宽度估为 4.4 mm，端部沿用 2.2 mm。拟合点投影的单坐标 RMS 从 11.65 px 降至 3.87 px，保存模型的中心线点到标注的二维距离 RMS 为 5.48 px。[像素与三维参数](fit.json) · [读回及支柱间隙](readback.json)

用完整模型的可见边界复测，第 120 帧两侧的最大偏差降至投影屏宽的 2.55% 和 2.66%。第 180 帧右侧增至 27.50%，未用于拟合的第 150 帧右侧增至 9.68%。这两个视角中，壳体与下部线束遮挡了部分回环。局部对照的红色区域为真实 CAD 可见回环，青色点为参考边缘。[遮挡和边缘对照](edges.jpg) · [逐点测量](visible-edges.json)

十方位视频、七张静态图和十格拼图平均 IoU 分别为 86.03733%、82.63270% 和 89.88232%。该试验未采用，正式模型为 v384。复建时将本目录 fit.json 传给 tools/experiment_drone_loop_path.py，使用 v384 保存文件和网格，半径参数为 4.4 和 2.2 mm。没有导出候选 STEP。[视频](video.json) · [静态](still.json) · [拼图](sheet.json)
