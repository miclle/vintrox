# v54 屏幕外框 220×172 mm 候选

本轮以已验证的 v53 3.5 mm 回环线束模型为基线，只修改 `ScreenBezel` 与 `BezelLip` 两件可见外框：内框外尺寸由 216×170 mm / 220×174 mm 调整为 220×172 mm / 224×176 mm，202×152 mm 开口、用户测量的 210×160×2 mm 平面屏和 200×150 mm 可视区保持。

沿用同一套视频十方位和七张静态图相机，不做图像变形或逐零件配准。当前正式 v54 视频平均 IoU 为 85.13408076%，相对 v53 3.5 mm 基线提升 0.041821 个百分点；静态图平均 IoU 为 82.04490633%，提升 0.002252 个百分点。视频 7/10 视角改善、1 个持平、2 个轻微退步；静态图 3/7 改善、4/7 轻微退步，退步保留在报告中。
