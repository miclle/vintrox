# 后壳凹舱与喷口阴影分离（2026-10-24）

用户指出，容纳喷口的后壳凹舱存在阴影，不能把暗边一概当成喷口的筒壁或外形。先固定 v30 喷口本体、出口及四支柱，只修改后壳开口、凹舱内衬和灯框三件，隔离检验其遮挡关系；所有候选使用相同十个视频相机、灯光、材质和分割方法。

参考中的金属口沿、叶片端边和线束接合可作为几何线索；光滑曲面上的亮暗分界只作为光照线索。此前 35 个外罩上缘手工点仍保留为局部诊断，但不能凭单个暗边或最低点距决定完整外罩几何。结合两侧后视、正后视和参考 04 的遮挡顺序判断。

| 候选 | 实际几何变化 | 判断 |
| --- | --- | --- |
| A | 后壳开矩形圆角窗口，原浅封板改为后退背板和内壁 | 凹舱开始产生真实阴影；粗亮框仍明显 |
| B | 加前压边并缩小灯框 | 压边遮掉参考中可见的上沿与侧沿，拒绝 |
| C | 扩大开口，调整细灯带与压边间隙 | 可见性改善，但灯带缺少实体承接 |
| D | 给 C 增加灯带安装台阶 | 接合通过，斜下方灯带仍勾出过完整边界 |
| E | 灯带和承接台阶后退 6mm | 斜段自然被遮挡，上沿、远侧竖边和底部仍露出，选入正式重建 |

各轮十方位轮廓 IoU 均为 84.37622%，因为改动集中在外轮廓内部；这不是总体还原率提升。候选 E 的四个凹腔空隙探针、四个内壁材料探针及两组实体接合通过。四根支柱与 v30 的对称实体差集均为零。开口 144 × 110mm、背板至压边约 24mm 及灯带深度均是外观推定，不是来源实测或制造尺寸。
