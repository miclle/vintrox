# v42 翼板姿态交叉检查（未采用）

正式模型保持 v42，SHA-256 `5534f124a394523e711ca6508d23d57754275f9be3ac0d45ec4e359a7a355cc0`。本次试验用于区分第 03 张参考图中的翼板投影缺口与后肩遮挡，未修改正式 FCStd、STEP 或交付预览。

## 方案与结果

补充视频 7s 金色翼板的 22 个手工外缘观察点，与原视频 1s 红色翼板轮廓联合拟合。相机保持；以各自轴座中心为支点，对两侧翼板作镜像刚性旋转：全局 X 轴约 0.023°、镜像 Y 轴约 1.758°。旋转角属于外观假设，不能视作原作测量。

单层翼板外线抽样 RMS 从 5.487 降至 4.898px；该近似不包含抬高面、折面厚度或遮挡。因此另外保存了真实 CAD 候选，渲染十个视频方位及七张独立参考图，沿用正式 v42 的相机、材质、分割阈值和比较规则。

| 比较 | v42 | 候选 A |
| --- | --- | --- |
| 十方位平均轮廓 IoU | 84.84236% | 84.75886% |
| 七张参考图均值 | 81.94409% | 82.04088% |

第 03 张图提高约 0.57946 个百分点，视频 7s 提高 0.21410 个百分点；但视频 0s / 4s 分别下降 0.49358 / 0.27645 个百分点，第 01 张图下降 0.74457 个百分点。七图均值含线框图，不能等同实体还原率。全部视角均保留，见 [逐视角结果](review.json)。

包含抬高面和折面的三倍像素完整翼板投影检查中，视频 1s / 6s / 2s 抽样 RMS 分别从 2.988 / 4.805 / 4.187 降至 1.787 / 4.789 / 4.165px。这说明局部抽样确有改善，但仍不能代替整圈比较。**本次不采用整体旋转方案，正式模型保持 v42。** 后续保留已建立的翼根和翼尖位置，检查局部外缘、折面及不同视图中的遮挡。

## 复现

使用 FreeCAD Python 运行 `tools/study_drone_wing_pose.py`，读取正式 v42，生成姿态拟合报告。再运行 `tools/experiment_drone_wing_pose.py`，输入同哈希基线 FCStd、网格及 `pose-fit.json`，在空目录生成候选。使用 `tools/render_drone_concept.py` 分别读取既定视频相机和 `stills-47/cameras.json`，再运行 `tools/compare_drone_reference.py`。

候选网格、实际生成时的脚本及只读检查脚本位于本机缓存，路径与哈希见 [review.json](review.json)。当前生成入口补充使用真实 `SpeakerHubNeck` 名称进行连接检查；本次候选的该项证据由独立读回报告提供。模型、渲染、叠加、失败记录均保留。
