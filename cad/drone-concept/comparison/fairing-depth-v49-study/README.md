# v50 喷口外罩深度与灯角避让

2026-10-24，采用 D4＋灯角让位。金色外罩的两个中间截面纵向半径各增加 4mm，两端截面不动；六条白纹、四片警示薄片随曲面重建，两处上方灯角端部避让外罩。共改 13 件，其余 685 个 BRep 原样保留，包括四根支柱、屏幕、后壳、凹舱、根环、出口、叶片和内部凹碗。尺寸为外观推导，未做制造或声学验证。

## 形体依据和取舍

固定视频第 60/180 帧的金色外罩外缘仍偏向机身，本轮只增加中段深度，并用第 90/120/150 帧复核上沿。深色凹舱仍是真实凹腔，未把阴影补成额外筒壁。灯条轴线、反光片与压座保持；两处灯角与外罩的新交叠通过局部修整解决。

| --- | ---: | ---: | ---: | --- |
| v49 基线 | 8.606 / 12px | 5.863 / 17.464px | 84.873585% | 对照 |
| D4 未让位 | 6.579 / 11px | 5.853 / 18px | 84.879448% | 与两处上方灯角各相交约 2.122mm³，未采用 |

| D4 灯角让位 / v50 | 6.579 / 11px | 5.853 / 18px | 84.879448% | 采用；12 件灯具与外罩无体积相交 |

仅完成表中三个试件，未声称搜索过连续最优解。失败检查及试件保留在 `d4/`、`d6-clearance/`；采用试件在 `d4-clearance/`。D4 让位前后轮廓分数一致，保留完整对比证据。

七张独立图平均轮廓 IoU 为 81.969512%，比 v49 增加约 0.00376 个百分点。video-02/06 分别增加 0.02404/0.03460 个百分点，still-05 增加 0.02629 个百分点，其余 14 个视图分数保持。上沿最大误差从 17.464 增至 18px，局部遮挡边界仍有退步。改善很小，90% 目标未达；轮廓分数不能解释成细节还原率，线框图尤其受分割方式影响。

七图已逐项核查：01/02/03/补充近景的正面主体保持，曲面显示与材质差异仍在；04/05 后部外罩侧缘更接近，但根部遮挡、叶片末端观感、后壳接缝和金属明暗仍有差距；06 线框只能辅助理解分层。优先继续核查上沿、后壳斜肩与凹舱的转折，不凭暗区形状拉长喷口。

[归档转移](archive-transfer.json)逐字节保留其余 BRep、GUI 清单与材质数据。保存模型为 700 个中文顶层对象、696 个可见对象，STEP 为 805 个实体。凹舱空点/材料探针、外罩表面贴片及灯条接合检查通过；原有 11 个翼板高级 BOP 问题仍存在，不作为制造交付。

原生打开检查发现历史转移代码以集合遍历 GUI 外部材质资源，打包顺序与 GUI 清单不同，会使 FreeCAD 1.1.4 跳过大量颜色。将 2094 个 GUI 资源按 XML 注册顺序排列后，[原生读回](native-open-check.json)的 696 个可见对象颜色全部与序列化材质一致。修复只改变 ZIP 条目顺序和包装；[逐条证明](gui-archive-order-proof.json)记录全部 3089 个条目内容一致。失败诊断也保留，未将读取异常隐藏为通过。

正式 FCStd SHA-256：`094bb2e63081b879e865db74d375f975126968bd2473772973c3dc0b2bd8171a`。采用候选：`efc7186b63652eab3579587e9e3f9243b245138eaeac0700776390fb13abcdd4`。重排前真实渲染模型：`848961152b53b1ef20940124418e2ffaab36cb5bf3268ca02a32acc2531e65a4`。

九张预览、96 个角度生成的 12 秒视频、17 个固定视图和对象分色来自重排前相同几何与材质；清单保留 `rendered_fcstd_sha256`，通过逐条一致性证明绑定正式文件，没有冒充重渲染。重排后重新执行保存读回、源构造/端面核对及全部当前测量，见[交付报告](../../delivery-verification.json)。
