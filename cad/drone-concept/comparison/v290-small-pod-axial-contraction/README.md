# v290 以口环为基准收短小喷口叶片

以 v287 保存模型为基线，固定小喷口局部 Z=36 mm 的口环站位，将叶片、压条、脊条和封片的轴向跨度缩至 94%。146 件修改形体通过保存读回及高级几何检查，216 项距离检查通过。FCStd 中其余成员与 v287 逐字节一致。[接合检查](candidate-check.json)

| 测量 | v287 | v290 |
| --- | ---: | ---: |
| 视频十方位平均 IoU | 86.033198% | 86.052303% |
| 静态七图平均 IoU | 82.574760% | 82.596617% |
| 拼图十格平均 IoU | 89.782809% | 89.788620% |
| 叶片外端圆弧，原拟合四视角 RMS | 4.53 px | 5.07 px |
| 叶片外端圆弧，原拟合外两视角 RMS | 7.38 px | 8.30 px |
| 叶片外端圆弧，原拟合外两视角最大偏差 | 12.62 px | 14.40 px |

三组整机均值提高，叶片端缘在原拟合视角和原拟合外视角的误差都增大。正式评审采用 v287，v290 用于继续定位端缘与外轮廓的差异。候选 STEP 与原生窗口颜色尚待复核。[叶片端缘读回](outline.json) · [视频十方位](video-comparison/comparison-board.png) · [静态七图](stills-comparison/comparison-board.png) · [拼图十格](sheet-comparison/comparison-board.png)

从 v287 保存模型重建网格，沿用 v289 脚本并传入 `--axial-scale .94 --anchor-z 36`。按 v287 三组固定相机重放并复测叶片外端圆弧。[复建流程](../v289-small-pod-axial-extension/README.md)
