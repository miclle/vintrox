# 后壳折转圆角研究

2026-10-24。测试半径 16 / 24mm 的后壳折转，原值为 8mm；均未采用，研究基线为 v43，后续正式修订见 [v44](../guard-notch-study/README.md)。尺寸是外观研究参数，不是原作测量。

## 几何与比较结果

先用半径 8mm 复现六件相关几何，全部双向实体差集小于 `1e-6mm³`，见 [基线源代码等价](baseline-source-equivalence.json)。候选保持竖直面、斜底面的原有平面位置，只扩大二者之间的过渡。后盖、外框、内衬和左右后肩同步构建；底部斜板复核后实际未变。

| 诊断 | v43 / R8 | R16 | R24 |
| --- | --- | --- | --- |
| 十方位轮廓 IoU | 84.84932% | 84.85014% | 84.85118% |
| 七图轮廓均值 | 81.94409% | 81.94441% | 81.94516% |
| 后下缘抽样 RMS | 3.54338px | 3.54338px | 3.63624px |
| 后下缘抽样最大误差 | 8px | 8px | 9px |

相机、材质、分割和支柱排除规则均保持。七图包含线框图，只作诊断；各视角改善与退步完整保存在 [review.json](review.json)。全圈变化不足 0.002 个百分点，无法据此认定形体明显改善。R24 的下缘误差增加，R16 也未解决侧后方可见的尖角和台阶，两者均不进入正式交付。

## 保存实体与后续方向

[保存剖面检查](saved-section-check.json)将模型在 X=80mm 处真实求交，绘制 [Y/Z 剖面](saved-section-check.png)。实际改变只出现在 Z=125～145mm 范围内；四支柱与喷口外罩的实体差集为零。六件构建及保存实体通过高级 BOP 检查，其中五件真正改变，底部斜板未变；其余 691 个可见网格记录保持。七组接合间隙为零。两候选的凹舱空位、壁面材料及支柱检查通过，见 [R16](r16/cavity-check.json) / [R24](r24/cavity-check.json)，没有把参考暗区补成筒壁。

放大比较进一步定位到状态板下方的保护边框：多次避让裁切留下台阶，参考边缘则连续斜收。后续优先处理该缺口，并重新验证状态板的多视角可见性；不以继续增加折转圆角替代这一问题。

构建入口为 `tools/experiment_drone_rear_fold.py`，保存剖面检查为 `tools/measure_drone_rear_fold.py`。冻结构建源码及两候选网格在本机缓存，路径、哈希和逐图结果见 [review.json](review.json)。本研究的 v43 基线哈希为 `d03080846462cd5b8318f6dea254456fe77ece6cda06349ba698ea010086d591`，未提交或推送，未做制造验证。
