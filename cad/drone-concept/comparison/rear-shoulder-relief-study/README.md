## 复现

使用 FreeCAD Python 运行 `tools/experiment_drone_rear_bow.py`，传入 v41 模型、同哈希网格、空输出目录及 `--exponent 1.5` / `1.75`。使用既定视频和独立图相机渲染，并运行后转折、后下沿检查。正式保存入口为 `tools/refine_drone_rear_shoulders.py`，源代码与保存几何检查为 `tools/measure_drone_rear_shoulders.py`。

候选、逐图渲染与检查保留。原始网格和诊断脚本在本机缓存，路径及哈希见 [mesh-cache.json](mesh-cache.json)。完整从头 GUI 重建的 OCCT 稳定性问题仍保留，未做制造或实物验收。
