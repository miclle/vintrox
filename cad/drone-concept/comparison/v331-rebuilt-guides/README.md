# v331 导轨截面重建

在 v329 保存模型中，沿喷口局部轴向对每根导轨从两端内移 0.01 mm，等分为 20 段并加入 Z=99 mm 接续截面。在闭合截面上取面积重心，按 v329 对应叶片在接续面以上的位移移动重心。每条导轨用截面等面积圆半径的中位数，沿这些点建立圆截面直纹放样。将 24 个 BRep 单独替换回 v329 的 FCStd。保存读回后，24 件均为单一有效闭合实体，高级曲面检查通过，与加强筋的最大间距低于 10⁻¹² mm。[逐件截面与接合](guide-check.json)

固定相机的视频、静态、拼图平均 IoU 分别为 86.01492%、82.61132%、89.87783%。正后方第 120 帧第 590 行的三个叶片加强筋可见，但对象 ID 无法分辨该行三组导轨的双边。该处亮边间距仍需要结合相邻行和斜侧面确认。正式采用 v329。[亮边核对](width.png) · [可见性读数](width.json) · [视频](video.json) · [静态](stills.json) · [拼图](sheet.json)
