# v51 喷口外罩上肩收形

2026-10-24，采用 U6：只把局部轴向 28mm 站位的横向半径减小 6mm，60mm 站位保持 v50；两端截面、纵向深度和根部位移权重保持。修改外罩及六条白纹、四片警示贴片共 11 件，其余 687 个 BRep 原样保留，包括四支柱、平面屏幕、后壳、凹舱、灯具、叶片和内碗。尺寸为外观推导，不是原作测绘或制造参数。

## 依据与试件

先检查源视频第 90～180 帧每隔 10 帧的连续画面，见[上沿与阴影复核](../upper-boundary-study/README.md)。第 120 帧右上旧测点受渐变阴影、反射和线缆遮挡影响，不能单凭最大误差将暗边当作筒壁。原 35 点指标完整保留，另用两侧黑背景外缘的 14 点、七张独立图和十个视频角度共同复核。

| 方案 | 上站 / 下站横向收量 | 上沿 RMS / 最大 | 侧缘 RMS / 最大 | 十方位 IoU |
| --- | ---: | ---: | ---: | ---: |
| v50 | 0 / 0mm | 5.853 / 18px | 6.579 / 11px | 84.879448% |
| S2 | 2 / 2mm | 5.495 / 16.553px | 6.585 / 11px | 84.879498% |
| S4 | 4 / 4mm | 5.082 / 13px | 6.671 / 11px | 84.879511% |
| S6 | 6 / 6mm | 4.943 / 11.180px | 6.974 / 11px | 84.878931% |
| U6 / v51 | 6 / 0mm | 4.908 / 11.180px | 6.579 / 11px | 84.879237% |

同时收窄上下站位会加重侧缘退步；U6 保持下站截面，试过的四个方案中上沿 RMS 最低，14 个侧缘点与 v50 相同。选择依据是多视角形体和局部边缘，不是最大化整机分数。十方位平均微降约 0.00021 个百分点，七图均值微增约 0.000088 个百分点至 81.969599%；所有视图的变化保留在[试件矩阵](trial-review.json)及[正式数值](review.json)。没有连续优化或全局最优结论，未测试 8mm 方案。

保持 60mm 站位不意味着其相邻曲面完全不变：平滑放样会影响整个插值跨度，在局部形成小幅外鼓。实际外罩仍有壁厚，端面有限采样和表面接合检查通过。凹舱阴影没有补成额外筒壁。

## 保存、包络与验证

[源/保存/候选检查](formal-geometry-check.json)覆盖 11 个修改实体、687 个保留形体、12 件灯具源构造、64 个端面采样；四支柱保持，零收量构造与精确 v50 基线的 11 件外罩/贴片等价。源构造和保存模型的双向布尔差通过，采样不代表连续壁厚或制造验收。

旧灯具避让包络不能完全包住新的插值跨度；新外罩被自身扩大 0.3mm 的包络包含。直接融合多个近重合历史包络出现布尔异常；对灯角额外切除新包络又会削去约 0.262mm³ 的原本无相交材料。最终保留 v50 的灯具避让切口，独立检查新外罩包络，并逐件检查实际灯具与实际外罩无体积相交。没有移动灯条或放宽几何阈值，失败日志保留在缓存执行目录。

[归档转移](archive-transfer.json)保留未改 BRep 和 GUI 材质内容，GUI 外部资源按 XML 顺序打包。[原生读回](native-open-check.json)核对 700 个顶层对象、696 个可见对象及全部可见颜色。FCStd SHA-256：`d78a7df3e0c30b9c9571b800d308b93ecc75080ae431346db978942929e9550d`；采用候选 SHA-256：`b7786b99e881c8900d2d0ca858d44cf9b1d462a4d6cdd451e3267b0dbd33fc38`。

保存读回、805 实体 STEP、九张静态预览、96 个角度的 12 秒转台、17 个固定视图和局部板均绑定正式模型，见[交付报告](../../delivery-verification.json)。原有 11 个翼板高级 BOP 问题仍存在；未打印、未装配、未声学测试。

## 复现

`tools/experiment_drone_fairing_shoulder.py` 使用精确 v50 模型和对应网格，U6 参数为 `--shoulder-inset 6 --lower-inset 0`，输出目录须为空。S2/S4/S6 的原始生成器和模块已分别冻结在对应目录；省略 `--lower-inset` 时两站采用相同收量。

`tools/refine_drone_fairing_shoulder.py` 转移候选并导出 STEP，`tools/measure_drone_fairing_shoulder.py` 核对保存实体和源构造。`diagnostic-scripts/review-candidate.py` 重跑全部固定比较，候选网格可按[缓存索引](mesh-cache.json)恢复到各试件的 `meshes.json`。精确 v50/v51 检查点、冻结源码、网格与日志均在缓存索引中登记。
