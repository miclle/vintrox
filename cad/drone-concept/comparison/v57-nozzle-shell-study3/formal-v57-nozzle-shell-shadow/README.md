# v57 喷口外罩与凹舱阴影收形

本轮把侧后方喷口拆成两个局部收形层：容纳喷口的 `BassNozzleShell` 在喷口局部 X/Y 方向收窄到 **0.96**，内腔、锥盆、12 片叶片及其凹槽细节收窄到 **0.90**；主叶片在局部 Z=94–102mm 保留根部搭接带。外罩上的警示牌、红白表面片同步收形，避免附着片脱离 BRep。

凹舱暗边继续解释为后壳的阴影/遮挡边界，未补成连续的喷口筒壁。四根支柱、后部检修板、后盖外框和左右后部护甲保持原几何。
