# v386 底部回环遮挡复测

v385 在第 180 帧的前侧管段受到机箱遮挡。使用 v384 全部相邻实体的三角网格，通过固定相机投射视线，计算投影位置处最近遮挡面的深度。以这份深度约束重新拟合 v385 的同一组中心线估计点。用于诊断的深度图单独处理回环，最后的遮挡、彩色渲染和三组整机评分均使用带两条回环的完整模型，并按既有约定从对比分割中排除四支柱。根部与底壳连接点保留，管中段半径改为 3.8 mm，两端为 2.2 mm。[三维路径及相机](fit.json) · [保存实体检查](readback.json)

第 180 帧峰值偏差从 v385 的 27.50% 降到投影屏宽的 21.09%，仍高于正式版的 5.82%。正后方两侧为 4.35% 和 2.69%，未参与拟合的第 150 帧为 9.64%。在斜视中，几段回环会与底壳和附近的线束重叠。给定其背面位置和截面未知，下一步需要独立的侧向观察来约束深度。[实际可见边缘](edges.jpg) · [逐像素归属](visible-edges.json)

视频十方位、静态七图与拼图十格的平均 IoU 分别为 86.09743%、82.61800%、89.88516%。保留为研究记录，正式模型为 v384。复建时向 tools/experiment_drone_loop_path.py 提供本目录 fit.json、v384 的保存 FCStd 与派生网格，设置半径 3.8 和 2.2 mm。本候选没有独立 STEP 读回。[视频](video.json) · [静态图](still.json) · [拼图](sheet.json)
