# v295 底部回环多视角拟合

在 v292 上重新拟合两条镜像回环。新增视频第 90 帧左回环的内外缘标注，第 180 帧右回环的像素残差权重提高到三倍，并约束靠近根部的两个控制点。四个端点维持原位置，端部半径为 2.2 mm，拟合中段半径为 5.28 mm。两个保存实体通过高级几何检查，端部保持与底壳搭接，和支撑总成的体积交叠为零。[拟合脚本](fit.py) · [控制点与采样](path-fit.json) · [几何复核](candidate-check.json)

第 180 帧的投影圆管近似拟合 RMS 为 3.29 px，保存几何按可见边缘复测为 12.08 px。第 150 帧的手工标注未用于生成候选，该帧可见边缘的 RMS 从 13.06 px 升至 15.71 px。视频十方位平均 IoU 从 86.034597% 降至 85.833576%。正式评审采用 v292。[视频对照](video-board.png) · [逐视角 IoU](video-comparison.json) · [拟合视图可见边缘](visible-loop-edges.json) · [第 150 帧近景](holdout-edges.png)

从仓库根目录在 FreeCAD Python 环境运行 `fit.py --output <拟合参数路径>`，并将 `tools` 加入 Python 模块搜索路径。使用 v294 的保存和渲染流程，按 `path-fit.json` 的半径重建候选。复测第 150 帧时，用 `holdout-observations.json` 作为候选目录中的 `path-fit.json`，运行对象 ID 边缘比较并核对第 150 帧的像素坐标。后续候选筛选可直接使用保存 CAD 的可见边缘，避免用投影圆管近似替代遮挡结果。[v294 复建流程](../v294-underbody-loop-screen/README.md) · [第 150 帧标注](holdout-observations.json)
