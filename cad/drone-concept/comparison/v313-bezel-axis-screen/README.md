# v313 屏框宽度与高度筛选

沿 v310 的固定相机，对屏框和压边分别测试横向每侧内收 1 mm、竖向每端内收 1 mm。保留实测平面屏、可视区和安装深度。两档各生成保存 FCStd、STEP 和 696 个网格对象，重建形体通过闭合实体与高级几何检查。[横向构建记录](width/candidate-check.json) · [竖向构建记录](height/candidate-check.json)

| 固定相机 | v310 | 横向内收 | 竖向内收 |
| --- | ---: | ---: | ---: |
| 视频十方位 | 86.184762% | 86.162384% | 86.180702% |
| 静态七图 | 82.639128% | 82.652687% | 82.639178% |
| 拼图十格 | 89.905496% | 89.881997% | 89.898917% |

横向内收使静态第 05 图提高 0.05111 个百分点，视频第 00 方位下降 0.06936 个百分点。竖向内收对静态均值的影响约为 0.00005 个百分点，视频与拼图均下降。正式模型采用 v310。[横向视频](width/video-board.png) · [横向静态](width/stills-board.png) · [竖向视频](height/video-board.png) · [竖向拼图](height/sheet-board.png)

用 FreeCAD Python 运行本目录的 `replay.py`，传入 v310 保存模型、对应重建网格、以该模型为显示来源、空输出目录与版本名称。横向档用 `--axis width --expansion=-.9`，竖向档用 `--axis height --expansion=-.9`。脚本参数相对于原 220 × 172 mm 屏框包络，v310 的宽、高余量均为 0.1 mm。按 v310 三组相机重放保存 CAD。[v310 保存输入与重建](../v310-right-wing-fold/README.md)
