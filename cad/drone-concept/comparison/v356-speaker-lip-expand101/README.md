# v356 扬声器外唇 1.01 倍筛选

v356 以 v345 为基线，只将左右 `SpeakerOuterLip` 与 `SpeakerLipTrim` 按对称真实 CAD 几何缩放到 `1.01`。四根支柱、实测 `210 × 160 × 2 mm` 平面屏、外挂筒、屏幕侧控件和格栅保持。

| 比较集 | v345 | v356 | 结论 |
| --- | ---: | ---: | --- |
| 视频十方位 | 86.2414280% | 86.2406197% | 微降 |
| 静态七图 | 82.7168109% | 82.7168089% | 持平 |
| 拼图十格 | 89.9819783% | 89.9816944% | 微降 |

三组没有一致改善，因此 v356 筛除，当前研究候选保持 v345。比较使用真实 CAD、固定相机、半透明叠加和差异图，没有图像变形、逐件配准或省略可见零件。

独立读回确认 698 个对象、696 个可见对象、853 个有效闭合 STEP 实体，保护支柱保持，四个外唇网格抽查通过，颜色和可见性从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设。
