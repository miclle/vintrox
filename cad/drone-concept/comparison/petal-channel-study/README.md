# 喷口叶片导轨与有底凹槽候选

2026-10-24。本轮只研究喷口叶片的表面层次，研究时正式交付为 v43，候选未替换其 FCStd、STEP 或预览。候选 C 的保存模型为 [candidate.FCStd](c/candidate.FCStd)，不是 v44 正式交付。整个后壳、凹舱和喷口外包络的还原目标仍未完成。

## 参考观察与候选取舍

[原图 04 近景](reference-mechanism-detail.png)显示上段压条、延伸到压条两侧的长导轨，以及下段有底的凹槽。暗部不能直接解释成贯通孔。观察范围、原图哈希和放大方式见 [reference-observations.json](reference-observations.json)；结构与尺寸均为外观推断。

A/B 仅扩大下段导轨间距，近景呈现下挂矩形框，未采用。C 保留下段有底凹槽，把双侧导轨向上延伸；导轨改为沿截面站位的圆截面放样，避免样条扫掠失败及球/柱布尔连接中的过小边。长凹槽与上段压条直接合并的试验产生高级 BOP 问题，未进入 C。失败源代码和日志按哈希保留，见 [review.json](review.json)。

C 的侧轨长度和凹槽层次较 v43 接近参考，但图 04 中压条表面仍偏平、下端转折偏方，整体喷口与后壳的形体差异也未由这些局部改动解决。因此保留为后续整合候选，不替换正式模型；下一轮优先回到后壳、凹舱和喷口的整体包络。

## 保存几何证据与复现

三个候选各改动 12 个加强条与 24 根导轨，其他 660 个可见网格记录（含材质、颜色）完全一致。保存几何签名亦保持其余对象，见各候选 `candidate-check.json`。C 的 [独立几何检查](c/geometry-check.json)确认：

- 36 个改动对象均为一个有效闭合实体，通过高级 BOP 检查，与生成几何的双向差集体积小于 `1e-6mm³`。
- 36 组接合距离近零；36 处内部探针确认槽中心为空、槽底仍有实体。探针为抽样，不证明整个厚度场。
- 四根支柱和 12 片主叶片相对 v43 的双向差集体积为零；叶片主轮廓、出口圆及周向位置未改变。

当前候选构建入口为 `tools/experiment_drone_petal_channel.py`，几何读回为 `tools/measure_drone_petal_channel.py`，像素宽度检查为 `tools/measure_drone_petal_channel_width.py`。A/B 使用冻结的旧构建脚本，C 使用冻结的当前脚本；网格与失败脚本放在本机任务缓存，其绝对路径与 SHA-256 见 [review.json](review.json)。渲染与对象 ID 使用既有比较工具和相机配置。缓存不是跨机器交付依赖的保证，需要迁移时按清单携带。

本研究的 v43 基线模型哈希为 `d03080846462cd5b8318f6dea254456fe77ece6cda06349ba698ea010086d591`。本轮没有提交或推送，未做打印、装配或制造验证。
