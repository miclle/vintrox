采用联合候选 B。正式模型 SHA-256 `d03080846462cd5b8318f6dea254456fe77ece6cda06349ba698ea010086d591`，基线 v42 为 `5534f124a394523e711ca6508d23d57754275f9be3ac0d45ec4e359a7a355cc0`。

## 形体与比较

上一轮整体旋转翼板使正面和正后方退步，本轮保持翼板基底、翼根与翼尖，只调整金色翼板抬高面、表面层和后缘折面三件。红色翼板、后壳、喷口和四支柱保持。局部站位 Y 偏移约 1.907 / 6.204 / 3.324mm，为外观拟合参数，不是原作测量。

双侧共用折线的试验只使抽样 RMS 从 6.813 降至 6.780px，未采用。金色一侧单独拟合视频 7s 的 A 改善该视角，但使 6s 抽样略退步；B 联合拟合金色一侧 6s / 7s，两个视角均改善。

## 保存几何与保留范围

[保存折线检查](../wing-crease-check.json)直接读取正式表面边缘。金色表面前缘、上方闭合边的双向抽样距离及折线两端差异均小于 `1e-6mm`。这不意味着每个投影像素都相同：新凸起表面使视频 4s 的 213 个 alpha 像素、8s 的 3 个像素变化，已保留记录。

[源代码等价](source-equivalence.json)和[正式几何读回](formal-geometry-check.json)验证三件与 B 候选差集为零，均为一个闭合实体且通过高级 BOP 检查；四组表面接合间隙为零，四支柱差集为零。[归档转移](archive-transfer.json)保留其余 695 个 BRep 文件与原 GUI 数据，693 个可见对象的网格、颜色及材质保持。[原生打开检查](native-open-check.json)通过，未再次保存。

表面改为先变换截面线框、再构建面与放样体，避免原非等比面变换中的曲线/曲面不一致。此前金色抬高面和表面层的高级检查问题已在本轮三件重建中消除；其余 11 个翼板对象的旧高级检查问题未在本轮处理。普通交付一致性通过仍不等于整体高级几何或制造验收。

## 复现与限制

局部构建函数位于 `tools/drone_wing_fold.py`，由 `tools/drone_concept.py` 在原比例变换后应用；保存入口为 `tools/refine_drone_wing_fold.py`。三件源代码与保存等价检查使用 `tools/measure_drone_wing_fold.py`，折线测量使用 `tools/measure_drone_wing_crease.py`。

共享、单侧和联合拟合脚本，以及 A/B 实际构建脚本、网格和 v42 源代码/模型，均按哈希保存在本机缓存，见 [review.json](review.json)。历史脚本读取 v42 的原始参数，不能直接把 v43 源码当作原拟合基线。完整 GUI 从头重建的既有 OCCT 稳定性限制仍保留；本轮以局部源代码等价和保存模型读回为证据，未做制造或实物验收。
