# v357 前脸颊外扩 1.005 倍筛选

v357 以 v345 为基线，对左右 `FrontCheek` 与桥板在模型中心 X=0 两侧做 `1.005` 倍真实 CAD 横向外扩。屏幕、四根支柱、外挂筒、屏幕侧控件和格栅保持。

| 比较集 | v345 | v357 | 结论 |
| --- | ---: | ---: | --- |
| 视频十方位 | 86.2414280% | 86.2457797% | 微升 |
| 静态七图 | 82.7168109% | 82.7168109% | 持平 |
| 拼图十格 | 89.9819783% | 89.9821941% | 微升 |

视频和拼图略升，静态持平，三组没有一致改善，因此 v357 筛除，当前研究候选保持 v345。比较使用真实 CAD、固定相机、半透明叠加和差异图，没有图像变形、逐件配准或省略可见零件。

独立读回确认 698 个对象、696 个可见对象、853 个有效闭合 STEP 实体，保护支柱保持，四个前脸颊对象网格抽查通过，颜色和可见性从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设。
