## 决定与实际观察

**不采用。** 后框前缘虽更柔和，但后盖与框之间形成更明显的细缝，参考图中没有同等强度的边界。极小且混合的分数变化不足以支持这次修改；也没有解决喷口末端及内侧明暗层次的差距。不能将材质、磨损、高光或凹舱阴影直接当作另一层筒壁。

## 几何与复现

[候选](r12/candidate.FCStd) 只改变 `RearStructuralFrame`；其余 697 个形体的保存读回几何签名一致，包含四根支柱、屏幕、后舱和喷口。修改件为单一闭合实体，高级 BRep 检查通过；减少约 605.054 mm³ 材料，增加体积为零。与后盖和左右后肩的最短间距为零，其中后肩为接触关系，并非实体重叠；不代表结构强度或制造验证。见[候选检查](r12/candidate-check.json)。

[生成器](../../../../tools/experiment_drone_rear_rim.py) 绑定 v48 FCStd 哈希，接受 `--baseline`、`--meshes`、`--output` 和 `--radius 1.2`。棱边编号仅适用于该哈希绑定的模型，不用于任意模型。生成器另允许 0.7mm；本研究只完成了 R1.2 的保存与全部视图比较，R0.7 仅做几何有效性探测，不是完整候选。

用 `render_drone_concept.py --meshes <候选网格> --model r12/candidate.FCStd --comparison ../cameras.json --output <输出目录>` 渲染视频组，再用 `compare_drone_reference.py` 生成比较；独立图组使用 `../stills-53/cameras.json`。两组均为 CPU，沿用正式渲染器。网格已移至[哈希绑定本机缓存](mesh-cache.json)；保存模型、渲染、比较和冻结生成器保留在本目录。`make-review.py` 根据已有渲染重建局部图和数值报告，其输出决定字段初始为待审，最终人工观察决定以本说明为准。

首次渲染命令遗漏候选 `--model`，被模型/网格哈希校验拒绝，未产生有效比较；补齐显式模型参数后完成两组渲染。正式 v48 及原交付证据未变。
