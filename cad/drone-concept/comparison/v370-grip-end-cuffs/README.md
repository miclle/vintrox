# v370 握把端箍

参考视频的握把包覆带两端由深色端箍接到提手臂。v369 的正后视图中，两个端箍上缘各有一处凹口。v370 从握把中心截取封闭截面，围绕截面中心等比放大 6%，在左右两端各拉伸 18 mm 并与原端箍融合。比例和长度用于外观拟合。保存读回后，两端与包覆带、握把芯和同侧提手臂均有体积搭接。[三方位近景](cuff-comparison.jpg) · [搭接体积](contact.json)

同一画面列中，从握把上方黑色背景向下寻找第一处可见边界。第 120 帧左、右端箍在所选区域的平均垂直偏差分别从 4.89、4.79 px 降至 0.78、0.70 px。第 150 帧从 2.21 降至 0.63 px。第 180 帧仍为 1.94 px，臂上缘与端箍之间的折线和突出部分需要继续调整。此测量只覆盖所列上缘，侧臂、包覆纹理和表面反射仍有差异。[坐标与局部误差](top-edges.json) · [测量脚本](measure.py)

使用 FreeCAD 1.1.4 的 Python 环境，按 [v369 复建说明](../v369-inner-wing-stripes/README.md) 恢复带红翼内侧斜纹的模型，再运行：

```sh
python cad/drone-concept/comparison/v370-grip-end-cuffs/build.py "$research_dir/v369.FCStd" "$research_dir/v370.FCStd"
```

验证覆盖 696 个可见对象。两端箍独立通过 FreeCAD 高级形体检查，导出的 STEP 与保存 FCStd 均有 869 个有效闭合实体，体积相对误差 5.15 × 10⁻⁷。原生四视角打开后未记录元素映射警告，显示与网格对应的颜色共 70 种。本次核验限于外观模型。[几何核验](independent.json) · [原生显示](native/native-display-verification.json)
