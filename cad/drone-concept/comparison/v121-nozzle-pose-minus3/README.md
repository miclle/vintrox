# v121 喷口总成反向姿态试验

从 v120 出发，将喷口外罩、叶片、导轨、铰座、标识和低音预留一体绕根部 X 轴反向旋转 −3°。真实 CAD 保存、143 件形体、11 组接合和原生颜色复核通过。参考曲面屏、隐藏结构和喷口内部仍有外观假设。

七组既有叶片末端采样中六组 RMS 下降，`video-06` 的最大采样偏差从 22.74% 升至 23.05%。视频十方位、静态七图和拼图十格均低于 v120，故落选。试验归档保留对照板和检查报告。[逐视角边缘](visible-petal-edges.png) · [接合检查](candidate-check.json) · [保存读回](readback-verification.json)
