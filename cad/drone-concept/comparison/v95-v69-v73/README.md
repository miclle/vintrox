# v95：v69 回环 + v73 表情组合外观基线

本轮将两个已完成独立证据的局部改动组合为当前 Drone 外观入口：

- `UnderbodyLoop0/1` 圆截面半径由 3.5 mm 收到 2.2 mm，中心线、四根支柱和其余实体保持；这是 v69 在固定相机下的视频与静态均值增益。
- `PixelMouth`、`PixelSmileHighlight` 使用视频 frame 270 通过固定相机反投影的真实 CAD 轮廓；实测平面屏仍为 210 × 160 × 2 mm，可视区仍为 200 × 150 mm，透明罩和参考曲面屏仍是外观假设。

保存的 `candidate.FCStd` 与 `candidate.step` 来自 v73 已恢复 GUI 外观的归档，入口模型同步到同一字节/哈希。独立读回通过：696 个可见对象、1008 个有效闭合 STEP 实体、平铺树、中文显示名、颜色数据、四根支柱与屏幕输入保持。

固定校准相机的真实 CAD 比较沿用 v69/v73 证据：视频十方位平均轮廓 IoU **85.553320%**，静态七图 **82.259620%**；v69/v73 没有图像拉伸、非刚性变形、逐部件配准或删除可见零件。表情局部比较在 video-00、video-08 留出视角改善，整机外轮廓保持。主要后壳/喷口包络仍低于 90% 目标，不能宣称完全一致。

`previews/`、`video-renders/`、`still-renders/`、`video-comparison/` 与 `stills-comparison/` 保存真实 CAD 网格、固定相机、半透明叠加和差异图；`archive-preservation.json` 记录未改 BRep 与 GUI 外观成员保持。所有结果仍属于静态外观研究，不代表制造、打印、装配、承力、光学、声学、热、电气或实物验收。
