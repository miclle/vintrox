## 局部观察与几何证据

- 第 120 帧第 590 行，两组共同可见导轨间距 RMS **6.519→0.791px**；中间一组遮挡，不补造数值。参考亮边未必是几何中心，人工不确定度约 ±2px，不能扩大成整个喷口精度。
- 48 个改动件为有效单一闭合实体，高级 BOP 检查通过；生产源码、候选和正式保存几何双向差集小于 `1e-6mm³`。
- 72 组接合间隙小于 0.01mm；36 处凹槽探针确认中间为空、槽底有实体。正式文件先验证与候选几何等价，再绑定候选探针证据。
- 四根支柱、12 片主叶片、金色喷口罩和卷边、后舱关键壳件双向差集为零。其余 650 个 BRep 文件及 GUI 状态原样保留，648 个可见对象的网格与材质保持。
