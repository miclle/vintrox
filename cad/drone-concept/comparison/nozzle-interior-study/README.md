## 根据可见性定位问题

[基线对象分色](baseline-id-audit.json)显示：正后方出口内部有 4011px 属于内锥面、2535px 属于连续内衬、240px 属于中央帽。原内锥面是实体放样，其前端有平封口；参考图则能看到下侧分片的背面及边缘。

- `bowl` 只掏空内锥面并后移中央帽，改动两件；十方位和七图轮廓分数完全保持，外观变化很小，主叶片内侧仍被连续内衬挡住。
- `recessed` 同时将连续内衬结束站位从局部 128.43mm 收到约 110.42mm，内锥面成为深约 23mm 的凹碗。原内衬遮挡区域中，正后方增加约 3604px 的主叶片可见面积，左右斜后分别约 3422px / 3310px，见[对象 ID 可见性分析](interior-visibility.json)。这只是遮挡归因，不是相似度分数。

内部轮廓是外观假设，不能根据参考暗部推断实际扬声器结构。凹碗使用约 1mm 径向壁构造与 1mm 轴向底板；不是已验证的最小法向壁厚或加工参数。
