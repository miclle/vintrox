# v392 两侧圆端格栅

参考旋转视频左、右两侧各能辨认十道圆端暗槽。以第 180、210 帧右翼下方格栅的首尾两道槽端为输入，沿冻结相机将四个端点分别投影到两幅参考图，最小二乘拟合格栅平面的位置、槽长与节距。在未参加拟合的第 150、240 帧，理想平面端点的单坐标 RMS 分别为 1.37、2.77 px。保存实体的对象 ID 渲染在这两帧均分出十个暗槽，实测槽端的单坐标 RMS 分别为 2.49、3.14 px。第 0、30、60 帧用于核对左侧镜像的可见性。近景从上到下为原视频、v388 和 v392。[七方位对照](grilles.jpg) · [标注和预测](fit.json)

两侧各十块金色面板都具有封闭的圆端槽，下方的深色衬板接触侧壳。每道槽长 42.2 mm，半径 1.24 mm，中心距 4.256 mm。拟合平面位于 X = ±114.08 mm。为在侧壳外侧完整显示槽面并让衬板接触侧壳，保存的格栅面位于 X = ±115.4 mm，中心 (Y, Z) = (10.12, 118.76) mm。黑色衬板的装饰深度按外观估计。圆端槽宽和面板厚度未经实物测量。二十块面板均接触各自衬板，22 件保存读回通过高级几何检查。运行 replay.py 并传入 v388 FCStd 和临时输出目录，可重建这批形体。用 tools/restore_candidate_display.py 恢复 v388 保存颜色，再按 mesh-archive.json 重建网格。[接合距离](joints.json) · [保存 FCStd](candidate.FCStd) · [STEP](candidate.step)
