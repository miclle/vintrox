# v360 小喷口外壳主体 1.005 倍筛选

v360 以 v345 为基线，仅将左右 `LowerPod_1` 与 `LowerPod_001` 保存真实 CAD 外壳在局部 XY 平面做 `1.005` 倍外扩，保持 Z 站位以及肋、口沿、夹块和膜片实体。屏幕、四根支柱、外挂筒、屏幕侧控件和格栅保持。

| 比较集 | v345 | v360 | 结论 |
| --- | ---: | ---: | --- |
| 视频十方位 | 86.2414280% | 86.2405530% | 回退 |
| 静态七图 | 82.7168109% | 82.7170102% | 基本持平，微回退 |
| 拼图十格 | 89.9819783% | 89.9811148% | 回退 |

三组没有一致改善，因此 v360 筛除，研究优选仍为 v345。比较使用真实 CAD、固定相机、半透明叠加和轮廓差异图，没有图像变形、逐件配准或省略可见零件。

候选保存读回与 STEP 导出检查确认 696 个可见对象、853 个有效闭合 STEP 实体，四根支柱保持，颜色和可见性从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设。
