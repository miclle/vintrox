# v334 喷口端角连续帧核对

在 v329 保存模型的十个固定视频方位上，CAD 超出参考前景的 413,054 个像素中，229,531 个位于参考掩膜的封闭暗区，183,523 个与背景连通。后一类中，叶片基体占 31,660 px，前罩内衬占 12,032 px，两侧小喷口肋条占 11,667 px。第 60 至 180 帧反复出现大喷口差异，暗色材料与真实孔隙都会影响该统计。[逐视角归因](boundary-regions.json)

从原始视频中分别选取三个可观察的叶片端角。在每个中央帧前后各追踪四帧，绿圈为端角，青圈为原测量中的最大误差点。各行沿用中央帧的固定裁切位置。用 15 × 15 像素灰度图块在相邻帧作归一化互相关匹配，三个序列的最低相关系数分别为 0.85、0.82、0.79，所有单步反向匹配均回到原像素。[连续帧](tracks.png) · [逐帧坐标](tracks.json)

| 中央帧 | 历史标注与可见边界距离 | 另行追踪的端角 | 端角与 v329 可见边界距离 | 最近可见 CAD 对象 |
| --- | ---: | --- | ---: | --- |
| 60 | 15.00 px | (280, 626) | 5.00 px | 第 5 号叶片折边 |
| 90 | 18.97 px | (263, 606) | 5.00 px | 第 10 号叶片 |
| 180 | 8.49 px | (632, 646) | 1.00 px | 第 0 号叶片折边 |

三处历史采样点在中央帧均落在暗色背景。新点随各自可见端角连续移动，两套采样对应不同像素。表中最近 CAD 对象按中央帧同相机对象 ID 求取。第 180 帧的新端角已接近折边，继续向旧点拉长第 0 号折边缺少图像依据。正式评审沿用既有七视角标注与 v329 的原评分。[正式记录](../v329-five-view-exit-ring/README.md)

复现时在 FreeCAD Python 中运行本目录的 track.py，传入原 video-cam.mp4、v329 视频对象 ID 目录、v329 评审目录以及输出目录，分别使用 --video、--ids、--formal、--output。十方位分区使用 tools/analyze_drone_boundary_regions.py，传入同一组对象 ID、正式视频渲染及对照目录。
