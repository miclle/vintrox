# 转台灯光坐标系试验（未采用）

正式模型和渲染设置保持 v53。只检验一个灯光假设：如果参考是模型在固定摄影棚下旋转，那么沿既定相机方位同步旋转摄影棚灯光，可得到等效相对照明。原作灯光未知；此试验不能证明原视频采用该设置。

全部 CAD 网格、相机、材质、曝光、灯光强度/尺寸以及支柱排除规则不变，仅整体绕固定中心旋转现有摄影棚灯具；所有视角使用同一规则，没有逐视角调灯。几何自身的发光灯条保持不动。配置见 [rig.json](rig.json)，每帧实际灯具矩阵记录在渲染清单。

## 结果与不采用理由

右后下斜面变亮，但后盖、喷口外罩及叶片同时偏亮，未消除与参考的表面层次差异。17 个视角的原始 alpha 通道逐像素完全相等，各视角轮廓 IoU 也逐项相等；十方位仍 85.03031%，七图仍 81.99829%。这不能算几何优化收益。

对象分色掩膜向内缩 3px 后，在相同像素上比较参考和 CAD 的 RGB 平均绝对误差（0～255，越低越小）：

| 部位 | 原灯光 | 方位同步灯光 |
| --- | ---: | ---: |
| 后盖与后肩 | 38.03 | 61.72 |
| 喷口外罩 | 44.34 | 49.46 |
| 喷口叶片 | 7.96 | 14.42 |

三个组均退步，因此不替换正式灯光。RGB 差还包含形体错位、材质、纹理与源图磨损，不能作为三维精度或整体相似度，也不能据此排除所有摄影棚布置。

[原像素诊断与逐图结果](lighting-diagnostic.json) · [选择记录](review.json)。不对源图进行亮度筛选、拉伸或扭曲；不改主轮廓阈值。

## 控制与复现

增加零旋转控制，使用相同包装器重新渲染十视角。对原渲染的最大 RGBA 差为 1/255、全图平均差不超过 0.000042/255，属于矩阵浮点舍入后的极少数像素变化；不能声称图像字节完全相同。原生 alpha 保持，控制结果见上述诊断。

冻结的 [方位试验源码](source-camera-yaw.py) 与 [零旋转控制源码](source-static-control.py)分别绑定各自渲染清单；正式渲染器未修改。辅助[字样可见性射线诊断](letter-visibility.json)用于区分文字遮挡与显示缩放影响，三角形中心的面积加权采样不是逐像素可见率验证。

运行 `tools/experiment_drone_orbit_lighting.py`，在正式渲染器参数后增加 `--rig-config <配置>`；必须使用 v53 同哈希网格。网格和正式模型来自 v53 检查点，本研究不重复复制。见[来源索引](provenance.json)和[研究包验证](study-validation.json)。

下一轮仍须依据真实可见边界处理后壳外侧转角和喷口金属层次，不将凹舱暗带补成筒壁，不因单张亮度改善而改正式灯光。90% 目标未达，无制造或实物验证。
