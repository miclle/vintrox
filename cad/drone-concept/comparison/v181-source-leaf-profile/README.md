# v181 源叶片末段曲面候选

在 v173 保存模型上，从保存的叶片根部截面重建 96 件叶片、导轨和随形细节。局部 Z=103 mm 之后使用二次进度，将终端逐步外移约 5 mm、局部 Y 方向外移约 7 mm、轴向延后约 9 mm。12 片叶片的实体和保存读回均通过，支柱和其余 602 件形体保持。
