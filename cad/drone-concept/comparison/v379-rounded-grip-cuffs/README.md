# v379 握把端箍圆滑过渡

正后视参考中，深色端箍包住握把两端并向提手臂过渡。v375 的端箍与包覆带之间可见窄亮带。取握把中面闭合截面，以 (0, 172, 301.5) mm 为缩放中心，在左右对称的 X = 92、96、104、108、111、113 mm 处放样。六站缩放比分别为 1.075、1.075、1.065、1.05、1.02、0.95，Z 偏移分别为 0、0、−0.05、−0.2、−0.5、−1.2 mm。将放样与各自端箍融合。两件均通过高级形体检查，分别与同侧提手臂搭接约 6634 mm³。[接合测量](geometry.json)

第 120 帧左右两组固定列的上边缘平均偏差从 1.08、0.97 px 降到 1.03、0.88 px。第 150 帧从 0.84 增到 1.21 px，新端面在斜视下突出于提手臂。第 180 帧为 1.94 px。候选留作截面试验，正式版采用 v375。[固定列测量](top-edges.json) · [两方位近景](cuffs.jpg)
