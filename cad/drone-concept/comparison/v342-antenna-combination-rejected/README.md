# v342 右翼折面组合候选（否决）

在 v341 基础上替换 v310 已验证的 `Antenna.Shape.brp`，尝试把右翼折面局部改进叠加到当前组合。真实 CAD 固定相机结果如下。

| 固定相机比较 | IoU |
| --- | ---: |
| 视频十方位 | 86.2096% |
| 静态七图 | 82.6612% |
| 拼图十格 | 89.9195% |

三组均低于 v341，因此否决，不替换正式 v339，也不作为下一轮组合基线。没有图像变形、逐部件配准或省略可见零件。

独立读回仍通过，FCStd 696 个可见对象、853 个闭合实体，STEP 853 个闭合实体，体积相对误差 `5.40e-7`。该结果说明几何和导出有效，但组合的整体视觉结果退步。
