候选 FCStd 仅保存几何，无 GUI 状态及 STEP，不能替代正式文件。正式 v30 已另行生成 FCStd、STEP、预览及比较证据。完整轮廓、材质和细节仍有差异。

复现须先从 v29 检查点提交 `fe11fe5` 取得模型与建模宏，重新生成与模型哈希绑定的网格；不要将当前 v30 误作 v29 基线。运行 `tools/experiment_drone_nozzle_fairing.py --base-model /v29模型.FCStd --base-meshes /v29网格.json --variant f --output /新的候选目录`；`--variant` 支持 a 至 f。候选目录不得覆盖正式模型目录。

候选 FCStd 与 meshes.json 分别传给渲染器的 `--model`、`--meshes`，使用固定 `comparison/cameras.json`。再执行 `tools/measure_drone_nozzle_fairing.py --ids /候选ID目录 --renders /候选渲染目录 --comparison /候选比较目录 --output /仓库内候选检查.json`。比较方法没有图像形变；使用 FreeCAD 自带 Python 和 Blender。
