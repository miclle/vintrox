# v312 握把高度筛选

固定相机近景中，参考握把的正后视包覆轮廓较平，斜视仍显示圆弧与折皱。以 v310 保存几何为基线，将握把芯及十条包覆带绕 Z=301.5 mm 平面沿高度缩至 97% 和 94%。两档各 11 件保存形体均有效闭合，14 项既有接合距离通过检查。高级几何检查仍报告部分曲线与曲面不一致，错误数量相对基线减少，记录见各档几何报告。[固定视角近景](grip-crops.png) · [正前与正后](grip-front-rear.png) · [97% 几何](height-97/candidate-check.json) · [94% 几何](height-94/candidate-check.json)

| 固定相机 | v310 | 97% 高度 | 94% 高度 |
| --- | ---: | ---: | ---: |
| 视频十方位 | 86.184762% | 86.121947% | 86.009033% |
| 静态七图 | 82.639128% | 82.636484% | 82.634205% |
| 拼图十格 | 89.905496% | 89.819356% | 89.727263% |

压低握把使视频和拼图的平均 IoU 随缩放幅度下降，正式采用 v310。本轮验证覆盖保存几何、接合与固定相机渲染。候选的 STEP 和原生四视图待验证。[97% 视频](height-97/video-board.png) · [97% 静态](height-97/stills-board.png) · [97% 拼图](height-97/sheet-board.png)

用 FreeCAD Python 运行本目录的 `replay.py`，传入 v310 保存 FCStd、重建网格、新输出目录和 `--height-scale .97` 或 `.94`。用保存的候选及对应网格沿用 v310 的三组相机重放渲染。[v310 保存输入](../v310-right-wing-fold/README.md)
