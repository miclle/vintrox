# v358 前罩横向外扩 1.005 倍筛选

v358 以 v345 为基线，对 `ProjectingBrow` 与 `BrowUnderside` 在模型中心 X=0 两侧做 `1.005` 倍真实 CAD 横向外扩。屏幕、四根支柱、外挂筒、屏幕侧控件和格栅保持。

| 比较集 | v345 | v358 | 结论 |
| --- | ---: | ---: | --- |
| 视频十方位 | 86.2414280% | 86.2501705% | 微升 |
| 静态七图 | 82.7168109% | 82.7054033% | 回退 |
| 拼图十格 | 89.9819783% | 89.9951708% | 微升 |

视频和拼图升高，静态回退，三组没有一致改善，因此 v358 筛除，当前研究候选保持 v345。比较使用真实 CAD、固定相机、半透明叠加和差异图，没有图像变形、逐件配准或省略可见零件。

独立读回确认 698 个对象、696 个可见对象、853 个有效闭合 STEP 实体，保护支柱保持，前罩两个对象网格抽查通过，颜色和可见性从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设。
