# v361-bottom-chassis-scale0995

以 v345 为基线，仅对 `BottomChassis` 保存真实 CAD 实体，以保存前端 `Y=11.25 mm` 为固定基准沿 Y 方向缩放 `0.995` 倍。屏幕、四根支柱、外挂筒、屏幕侧控件和格栅保持。

| 比较集 | v345 | v361-bottom-chassis-scale0995 |
| --- | ---: | ---: |
| 视频十方位 | 86.2414280% | 86.2427077% |
| 静态七图 | 82.7168109% | 82.7172664% |
| 拼图十格 | 89.9819783% | 89.9823904% |

三组固定相机渲染、半透明叠加和轮廓差异均已完成。保留为当前研究候选，但不替换 v345。增量处于渲染和三角化噪声量级，不能据此宣称达到 90% 整圈目标。

独立读回确认 696 个可见对象、853 个有效闭合 STEP 实体，`BottomChassis` 与主壳、腹板、小喷口和底部回环的接合保持。颜色和可见性从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设。

候选目录仅保留摘要、哈希、相机配置和比较报告，可再生的大型 FCStd、STEP、网格和 PNG 已清理。
