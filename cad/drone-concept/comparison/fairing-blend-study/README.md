# v49 喷口外罩根部影响范围修订

2026-10-24，正式采用 P4。四根支柱、实测平面屏幕、后壳、喷口根环、出口圆、十二片叶片和内部凹碗保持。本轮只改变金色外罩及六条白纹、四片警示贴片，共 11 个对象，其余 687 个 BRep 数据块及全部 GUI 数据原样保留。尺寸为外观推导，尚未做制造或声学验证。

## 依据与结果

v47 为修正根环位置，把外罩中段一起移向机身，导致固定视频第 60/180 帧的金色侧缘 14 点 RMS 增至 12.57px。本轮把沿外罩长度的根部位移权重由 `t` 改为 `t⁴`；两端保持，减小中段受到根部平移、半径和倾角修订的影响。外罩仍是有厚度的真实壳体，贴片随新曲面重建。没有把凹舱阴影补成额外筒壁。

| 固定相机诊断 | v48 | v49 |
| --- | ---: | ---: |
| 十方位平均轮廓 IoU | 84.859968% | 84.873585% |
| 七张参考图平均轮廓 IoU | 81.958539% | 81.965757% |
| 两侧金色外罩 14 点 RMS / 最大 | 12.567 / 14px | 8.606 / 12px |
| 上缘 35 点 RMS / 最大 | 6.148 / 16.492px | 5.863 / 17.464px |

上缘 RMS 虽下降，但最大误差从 16.492 增至 17.464px，局部遮挡边界仍需继续修订。17 个视图均没有轮廓分数退步；video-02/06 分别提高约 0.05950/0.07667 个百分点，still-05 提高约 0.05052 个百分点，其余视图分数相同。正式模型与候选的逐视图轮廓分数完全一致。七图包含线框图，均值不能解释成实体还原率。图像阈值、相机、材质、灯光和支柱排除规则保持，未做图像拉伸或逐件配准。

改善仍小，90% 目标未达。喷口叶片末端、内侧明暗层次、后壳过渡及材质仍有差距；本轮没有通过调整叶片长度追求静态图局部匹配，因为原视频出口圆误差约 3.3px，此前收口试件导致多角度退步。

## 复现入口

`tools/experiment_drone_fairing_blend.py` 接受 v48 的 `--base-model`、哈希对应的 `--base-meshes`、空输出目录 `--output` 和 `--blend-power 4`。源构造在 `tools/drone_fairing_blend.py`，P1 构造与基线 11 件等价已检查；只完成 P4 的全部固定视图比较，没有声称其它幂次已验证。

`tools/refine_drone_fairing_blend.py` 转移 11 个候选实体并导出 STEP，`tools/measure_drone_fairing_blend.py` 绑定原 v48 文件哈希并检查源/保存/候选。原检查点文件已丢失，恢复对照文件不能冒充该入口要求的原文件；可依据恢复记录进行几何研究，历史严格哈希的端到端复跑仍需要原文件。这一限制不影响已保存的正式模型、逐件载荷证据或本次重新生成的当前检查。

正式几何生成器调用 `nozzle_fairing_parts()`，采用权重 4；凹舱灯具沿用此前更大的避让包络，经当前 12 件灯具无相交检查。源代码、候选网格和恢复对照文件的本机缓存位置与哈希记录在 `mesh-cache.json`，运行日志也保留。没有提交或推送。
