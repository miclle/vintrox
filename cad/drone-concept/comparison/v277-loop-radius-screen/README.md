# v277 底部回环渐变半径筛选

视频第 02 至 07 方位中，参考回环的外露弧段普遍比 v276 粗。沿用 v276 的镜像中心线、40 个放样截面和四个端点，分别筛选 3.5 mm 与 4.5 mm 的中部半径，两端均保留 2.2 mm。半径增量沿归一化路径参数按正弦平方分布。两档通过了保存实体、四个端点与底壳交叠以及支撑净空检查。统一半径的两档则与中央支柱座分别新增约 7.06 和 76.09 mm³ 交叠。[六方位近景](loop-crop.png) · [放样参数](path-fit.json) · [读回和接合](replay-check.json)

| 候选 | 视频十方位平均 IoU | 变化（百分点） | 第 180 帧右回环采样 RMS |
| --- | ---: | ---: | ---: |
| v276 | 86.019486% | 基线 | 5.50 px |
| 3.5 mm 渐变 | 85.966649% | −0.052838 | 5.15 px |
| 4.5 mm 渐变 | 85.923009% | −0.096477 | 5.09 px |

两档在四组既有标注点上均降低 RMS。第 60 帧的最大采样偏差仍为投影屏宽的 15.16%，第 180 帧仍约为 6.28%。局部改善伴随视频整圈均值下降，正式模型继续采用 v276。试验停在视频筛选；静态图、拼图、STEP 和原生显示复核留待后续有综合收益的候选。[3.5 mm 十方位](taper-3.5/video-comparison/comparison-board.png) · [4.5 mm 十方位](taper-4.5/video-comparison/comparison-board.png) · [4.5 mm 局部采样](taper-4.5/visible-loop-edges.png)

从 v276 保存模型导出临时网格后，运行 `tools/experiment_drone_loop_path.py`。把保存模型和网格传给 `--base`、`--mesh`，把本目录的 `path-fit.json` 传给 `--fit`，指定新的 `--output`，并使用 `--radius 4.5 --end-radius 2.2`。重复时可将中部半径改为 3.5 mm。该入口已重建两档候选的回环 BRep，并与用于评分的 BRep 逐字节核对。用原固定视频相机重放渲染和叠加，局部采样沿用 v130 的回环标注。[渲染流程](../../../../docs/drone-concept.md#编辑与复现) · [原始标注](../v130-underbody-loop-path/path-fit.json)
