# v326 底盘长度试验

固定底盘前端 Y=11.25 mm，以 v315 保存模型为基线改变 BottomChassis 长度。原始后缘在 Y=202.35 mm。六档候选完成静态七图筛选，三个缩短档位补测视频与拼图。各组沿用 v315 固定相机、支柱排除范围和参考遮罩。[逐视角测量](screening.json)

| Y 向系数 | 视频十方位 | 静态七图 | 拼图十格 |
| --- | ---: | ---: | ---: |
| v315 | 86.204590% | 82.687714% | 89.958234% |
| .965 | 86.209013% | 82.691312% | 89.957359% |
| .97 | 86.208420% | 82.690717% | 89.957503% |
| .975 | 86.207931% | 82.690131% | 89.957472% |
| .98 | — | 82.689615% | — |
| 1.02 | — | 82.686137% | — |
| 1.03 | — | 82.685543% | — |

0.965 档的后缘前移约 6.69 mm。在第 05 张静态图中，比较两版 CAD 的 alpha > 127 遮罩，整幅 960 × 823 图像仅移除 64 个前景像素。差异集中在底盘左侧的一小段边缘，参考图中该处为暗色。该图中小喷口和底部线束仍有明显的形状与位置差异。[参考图、原模型、候选与差异近景](still-05-detail.png)

独立打开 v315 和三个缩短候选的 FCStd，测量底盘与主壳、托壳、控制条、两个底部回环、两侧小喷口及根箍的形体间距和交叠体积，九处原有接合均保留。三个缩短档位的视频与静态均值微升，拼图均值均下降。底盘外缘证据不足以采用该长度改动，正式评审继续使用 v315。[九处接合测量](contacts.json)

复现时在 FreeCAD Python 中运行 `tools/experiment_drone_bottom_chassis_y.py --base <v315 FCStd> --scale <系数> --output <临时目录>`，用 `tools/restore_candidate_display.py` 从 v315 恢复显示，再用 `tools/export_candidate_drone_meshes.py` 从恢复后的 FCStd 重建网格。沿 v315 保存相机运行 `tools/render_drone_concept.py` 和 `tools/compare_drone_reference.py`。本轮原始试验 STEP 包含两个隐藏占位件，固定相机渲染使用恢复显示后的可见对象。现已修正试验导出器，重放 0.965 档仅导出 696 个可见对象，独立读回得到 853 个闭合且体积为正的 STEP 实体。正式交付包及颜色核验见 [v315](../v315-antenna-multiview/README.md)。
