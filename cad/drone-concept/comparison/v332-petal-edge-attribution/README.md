# v332 大喷口叶片边界归因

逐点检查 v329 七个标注视角中的最大误差。图中青圈为原有参考标注，红圈为整组叶片最近的可见边界，各列为原图、真实 CAD、对象 ID。每幅近景使用同一像素裁切。第 60、90、180 帧的最大误差点都落在黑色或近黑色参考像素上，第 90 帧的采样点尤其明显地偏离可辨端角。第 150 帧及静态第 04 图可辨出亮色实体边。需要保留原标注的不确定性，并核对邻近帧中同一实体边的移动。[参考与 CAD 局部近景](extrema.png) · [原点与像素值](extrema.json)

原测量将 12 片叶片和附属件合成一个可见区域，相邻叶片互相遮挡的交界有时位于区域内部。本次补充逐片边界距离，把各片自身的折边、导轨与加强筋归到对应的叶片，再单独提取每一片的可见边界。使用所有原标注，按最近距离寻找边界，归属仍可能混淆。
