# v330 喷口导轨接续试验

v329 正后方视频第 120 帧第 590 行可辨三处加强筋，但对象 ID 在该行没有分辨出三个指定叶片的两条导轨。该行的参考亮边间距为 12、13 和 11 px，实体归属和高光位置存在不确定性。[采样行](v329-guide-width.png) · [原始读数](v329-guide-width.json)

在 v329 的五视角端环重放中增加 `--follow-guides`，使 24 条导轨的末段沿相应叶片一起变形。96 件修改形体经保存读回，13 件支撑构件的形体差集为零，导轨和加强筋的 24 项接合距离均通过。全部 24 件导轨出现新增高级几何错误，试验止于几何核验。后续可从导轨中心线重新扫掠圆截面并核对局部间隙。[几何及失败记录](geometry.json) · [五视角重放](../v329-five-view-exit-ring/README.md)
