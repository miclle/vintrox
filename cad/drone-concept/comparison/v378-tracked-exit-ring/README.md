# v378 以连续端缘约束喷口姿态

用 v377 保存的六条原视频端角轨迹估计出口圆。拟合固定圆心 X=0，最小化各三维点的轴向距离及径向偏差。各点残差除以两半轨迹解之间距离的平方根，距离下限为 1 mm。估计圆心 Y=244.21 mm、Z=65.69 mm，半径 39.25 mm，轴线相对竖直向下倾斜 32.65°。角度及半径依赖镜头与轨迹对应关系。[原图轨迹](../v377-tracked-tip-splice/rim-tracks.json) · [拟合参数](trajectory-ring.json)

从 v375 的每组铰链及折边取实体体积加权中心，将折边目标设为拟合圆上的最近点。绕铰链中心旋转整组叶片，使中心连线指向目标。12 组共 108 件，逐件刚体旋转，转角 2.21° 至 22.81°。120 处邻件距离复测的最大增量小于 0.000001 mm。几组折边与目标仍相差约 10 mm，需进一步核对叶片长度和根部位置。[逐组轴线与转角](rigid-ring.json) · [接合对照](contacts.json)

所有七个既有末缘视角的最大采样偏差均下降。第 60、180 帧从 v375 的 20.96%、21.94% 降为 18.29%、17.55%，静态第 04 图从 5.08% 降至 3.89%。第 180 帧连续端角距最近可见叶片边缘 20.81 px，高于 v377 的 1 px。三组整机 IoU 分别为 86.22132%、82.70653%、89.98709%，正式模型采用 v375。本次记录覆盖固定相机和保存几何，候选 STEP 未独立读回。[原图与三个模型](rear.jpg) · [部件采样](visible-components.json) · [视频](video.json) · [静态](stills.json) · [拼图](sheet.json)

复建时从 v375 原模型读取每组以 NozzlePetal 开头的对象，按叶片编号及附件后缀归组。对刚体副本使用 rigid-ring.json 对应的 pivot、axis、angle_deg 调用 Shape.rotate，保存后恢复 v375 GUI 载荷并重新导出网格。模型及原始相机的哈希见逐组评分报告。
