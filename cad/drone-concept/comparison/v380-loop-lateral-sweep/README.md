# v380 底部回环的横向弯曲

在 v375 上将两根回环的 X 坐标向 v295 的多视角解移动 65%，保留各控制点原有的 Y、Z 及四个根部位置。圆截面半径由端部 2.2 mm 渐增到中部 3.8 mm。两根保存回环均为闭合实体，四个端部与底壳的球形探针交叠各为 44.60 mm³，与支柱总成的体积交叠为零。使用 tools/experiment_drone_loop_path.py，传入 v375 保存文件与网格、本目录 fit.json、参数 --radius 3.8 和 --end-radius 2.2。[路径参数](fit.json)

第 120 帧左、右回环的最大边缘偏差分别从投影屏宽的 9.15%、10.58% 降至 4.45%、6.55%。第 180 帧右回环的峰值维持 5.82%。未参与路径拟合的第 150 帧右回环峰值从 5.94% 增至 8.71%。固定相机的十方位、静态七图、拼图十格均值分别为 86.16753%、82.68943%、89.93317%。该版本用于比较横向弯曲和回环粗细，正式模型采用 v375。[可见边界](edges.jpg) · [逐点记录](visible-loop-edges.json) · [视频](video.json) · [静态](stills.json) · [拼图](sheet.json)
