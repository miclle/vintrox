# v263 镜像大喷口叶片局部筛选

从 v259 保存模型出发，使用保存 CAD 的局部切向收窄，根部 8 mm 保持不动。`0_4` 收窄第 0、4 号镜像叶片，`5_11_f095` 收窄第 5、11 号镜像叶片，后者采用 0.95 倍。

| 候选 | 视频十方位 | 静态七图 | 拼图十格 | 决策 |
| --- | ---: | ---: | ---: | --- |
| v259 基线 | 86.008085% | 82.574342% | 89.772706% | 正式入口 |
| 0/4，0.90 | 86.013883% | 82.581849% | 89.778456% | 不采用 |
| 5/11，0.95 | 86.008690% | 未完成 | 未完成 | 不采用 |

`0/4` 在三组相机均提高约 0.000058 个百分点，属于渲染和三角化噪声量级。`5/11` 视频仅提高约 0.000006 个百分点。两组都不替换正式 v259。候选实体保存读回有效，`0/4` 的 STEP 独立读回为 869 个闭合有效实体，`5/11` 为 866 个闭合有效实体。

`0/4` 的完整视频、静态图和拼图证据均已保存。`5/11` 仅保存视频证据，静态图和拼图未继续运行。所有比较使用同一真实 CAD 渲染、固定相机和支柱排除范围，没有图像变形、逐件配准或删除可见零件。
