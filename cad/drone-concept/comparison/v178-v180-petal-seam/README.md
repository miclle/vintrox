# v178–v180 喷口叶片末段接续试验

基于 v173 保存的末端折边和七个固定视角的 53 个样点，估算局部接续站之后的轴向长度、半径和中心线偏移。Z = 100 mm 档将视频第 06 视角的投影 RMS 从 27.63 px 降至 11.33 px。这个拟合允许遮挡处的折边参与最近距离计算。实际可见边缘及整机轮廓仍需用通过实体检查的试件评估。[投影拟合](anchored-tip-fit.json)

v178 以 Z = 100 mm、轴向因子 1.50、每 17 mm 径向与局部 Y 偏移 9.84 和 9.32 mm 构建。第 0 号叶片接续后出现无法定向的形体。v179 将两项偏移减至 7 和 3.5 mm，保存读回后有四个叶片或脊条对象出现曲面曲线错误。五组补充筛查同样出现新错误。正式入口采用 v173，后续曲面重建可使用拟合记录中的末段位置作对照，并核对根环、铰座和随形细节的接合。[v179 实体报告](v179-candidate-check.json) · [五组接续筛查](shape-grid.json)

试件使用 `tools/experiment_drone_petal_axial.py` 的 `tip-splice` 构造，从 v173 的保存 FCStd 及重建网格出发。两项偏移以原轴向跨度 17 mm 归一化。
