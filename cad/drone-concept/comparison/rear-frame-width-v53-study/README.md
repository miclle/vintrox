# v53 后盖外框宽度试验（未采用）

对象 ID 叠加把后方两侧的金色框识别为 `RearStructuralFrame`，因此测试其原始 178mm 宽度的 ±6mm 真实 CAD 候选。后盖面板、后肩、凹舱、喷口与四根支柱保持。

| 候选 | 视频十方位 | 七图 | 处理 |
| --- | ---: | ---: | --- |
| v53 / 178mm | 85.03031% | 81.99829% | 正式 |
| 172mm | 85.02863% | 81.99837% | 不采用 |
| 184mm | 85.02678% | 81.99656% | 不采用 |

缩窄在视频 1/2/6/7 秒退步，放宽在视频 1/2/6 秒退步更明显；七图的小幅变化不足以抵消视频回归。每个候选只改变 `RearStructuralFrame`，697 个其它形体和四根支柱保持，后盖及凹舱接合检查通过。
