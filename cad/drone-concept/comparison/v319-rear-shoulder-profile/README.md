# v319 后肩折面指数筛选

以 v315 保存的真实 CAD 为基线，重建左右后肩护甲并保留状态开口、侧防护与四根支柱。筛选折面指数 1.25 和 1.75，两档各改变左右 RearArmourCheek，保存几何检查保留 696 个原对象和 13 件支柱保护。

| 固定相机 | v315 | 指数 1.25 | 指数 1.75 |
| --- | ---: | ---: | ---: |
| 视频十方位 | 86.204590% | 86.197078% | 86.164977% |
| 静态七图 | 82.687714% | 82.676288% | 82.613995% |
| 拼图十格 | 89.958234% | 89.948281% | 89.959454% |

两档都使视频和静态平均 IoU 下降。1.75 档拼图略高于 v315，仍不足以抵消视频与静态退步，正式模型保持 v315。

候选从 v315 保存 FCStd 临时重建网格运行 `tools/experiment_drone_rear_shoulder_section.py --exponent 1.25` 或 `1.75`。本轮修复了该脚本原本只接受早期 1.5 指数基线的门槛，修复差异单独留档，网格不随仓库提交，正式工具文件未改变。[v315 输入](../v315-antenna-multiview/README.md)
