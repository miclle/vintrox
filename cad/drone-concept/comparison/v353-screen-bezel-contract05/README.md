# v353 屏幕外框每侧收缩 0.5 mm 筛选

v353 以 v345 为基线，只将 `ScreenBezel` 与 `BezelLip` 的外轮廓每侧收缩 0.5 mm，保留 202 × 152 mm 开口、实测 210 × 160 × 2 mm 平面屏、四根支柱、外挂筒、屏幕侧控件和格栅。

| 比较集 | v345 | v353 | 结论 |
| --- | ---: | ---: | --- |
| 视频十方位 | 86.2414280% | 86.2255781% | 回退 |
| 静态七图 | 82.7168109% | 82.7299900% | 上升 |
| 拼图十格 | 89.9819783% | 89.9656353% | 回退 |

三组没有一致改善，因此 v353 筛除，当前研究候选保持 v345。比较使用真实 CAD、固定相机、半透明叠加和差异图，没有图像变形、逐件配准或省略可见零件。

独立读回确认 698 个对象、696 个可见对象、853 个有效闭合 STEP 实体，保护支柱保持，`ScreenBezel` 与 `BezelLip` 网格抽查通过，颜色和可见性从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设。
