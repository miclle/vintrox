# v352 小喷口肋切向 0.995 倍筛选

v352 以 v345 为基线，只对 36 个 `LowerPodRib` 保存真实 CAD 实体在各自局部肋框架内做切向 `0.995` 倍缩放，根部、末端站位、屏幕、四根支柱、外挂筒、屏幕侧控件和格栅保持。

固定相机结果如下。

| 比较集 | 平均轮廓 IoU |
| --- | ---: |
| 视频十方位 | 86.2415751% |
| 静态七图 | 82.7172183% |
| 拼图十格 | 89.9813922% |

视频和静态相对 v345 略升，拼图略降，三组未形成一致改善，因此 v352 筛除，当前研究候选继续保持 v345。比较使用真实 CAD 三角网格、固定透视相机、半透明叠加和差异图，没有图像变形、拉伸、逐部件配准或省略可见零件。

独立读回确认保存模型有 698 个对象、696 个可见对象，STEP 有 853 个有效闭合实体，保护支柱与 v345 相同，抽查肋网格与保存读回一致。颜色和可见性载荷从 v345 恢复。平面屏、曲面罩和不可观察细节仍是外观假设，不代表制造、装配、光学或实物验收。
